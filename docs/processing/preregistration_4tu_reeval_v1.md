### 1-6. 실행 실패 처리 (미리 정함)

| 상황 | 처리 |
|---|---|
| 중복 목록 해시 대조 불일치(깊이 계산 전 `ValueError`) | 자료가 바뀐 것이다. 중단하고 사용자·gpr-dataset-curator에 보고한다. 목록·코드를 고치면 이 문서를 개정(고정 값 갱신, 이력 기록)한 뒤 실행한다 |
| 출력 전에 예외로 중단(출력 파일 없음) | 출력은 모든 계산이 끝난 뒤 한꺼번에 쓴다(`_write_outputs`). 원인이 환경(메모리·디스크·권한)이면 같은 커밋·같은 명령으로 다시 돈다. 코드 결함이면 python-expert가 고치고, 주 경로 출력 불변 회귀(G8·D9·N1류)를 통과한 새 커밋으로 이 문서의 고정 값을 갱신(이력에 차이 기록)한 뒤 돈다. 이것은 "1회"를 어기는 재실행이 아니다(결과를 보지 않았음) |

## 2. 주 판정 기준과 계산식 (b)

### 2-1. 주 조합

`variant = main`(QC 규칙 B+D+E, 완전 연결 묶기 폭 0.10 m, 지지 측선 ≥ 2), 활동 간 중복 `keep_both`(둘 다 유지, 사용자 결정 11), 활동 안 사본(09.5 Path12–16) 제외, `gt_set = exclude_x`, `assumption = top`(관 상단, 사용자 결정 2026-11-07), `zero_variant = detected`(검출 영점, 사용자 결정 2026-11-07), `scope = all`. summary csv와 md "## 주 결과" 표의 첫 행(`top`, `detected`)이다.

### 2-2. 판정률 B

$$B=\frac{n_\text{pass}}{N_g},\qquad n_\text{pass}=\sum_{a\in\mathcal G}\#\{(i,j)\in H_a:\ |\hat d_i-d_j|\le g+\tau\}$$

| 기호 | 정의 | 단위 |
|---|---|---|
| $\mathcal G$ | 정답이 있는 활동(`exclude_x`) — 93개 | – |
| $N_g$ | $\mathcal G$의 정답 수 합 — 388 | 개 |
| $\hat d_i$ | 활동 $a$의 추정 깊이(묶음 깊이, 지지 필터 뒤) | m |
| $d_j$ | 정답 깊이(상단 가정 = `depth_m`) | m |
| $H_a$ | 비용 $\lvert\hat d_i-d_j\rvert$의 게이트 없는 헝가리안 짝, $\lvert H_a\rvert=\min(n_{e,a},n_{g,a})$ | – |
| $g$ | 제186조 허용 0.30(공공측량 작업규정 제186조, 깊이 3 m 이하 ±30 cm) | m |
| $\tau$ | 부동소수 허용치 $10^{-12}$(`PASS_TOL_M`) | m |
| $n_\text{pass}$ | ±0.30 m 안 짝 수(정수) | 개 |
| $n_\text{pairs}$ | $\sum_a\lvert H_a\rvert$ | 개 |
| $A$ | 판정률 A $=n_\text{pass}/n_\text{pairs}$ | – |
| $B_\text{max}$ | 판정률 B 상한 $=n_\text{pairs}/N_g$ (그래서 $B=A\,B_\text{max}$) | – |

- $n_\text{pass}$는 matches csv에서 주 조합 행의 `within_30cm == True` 개수로 세고, summary `pass_b`×388과 같은지 확인한다(소수 4자리 반올림이라 정수가 하나로 정해진다).

### 2-3. 무작위 기준선 $p$

$$p=\frac{1}{K}\,\#\{k=1..K:\ n^{(k)}_\text{pass}\ge n_\text{pass}\}$$

| 기호 | 정의 | 단위 |
|---|---|---|
| $K$ | 주 조합 활동 범위 기준선 시행 수 1,000 | 회 |
| $n^{(k)}_\text{pass}$ | $k$번째 시행: 활동마다 $n_{e,a}$개(관측과 같은 수)를 $U[\min d_\text{gt},\max d_\text{gt}]$(정답 1개면 $U[d-0.3,d+0.3]$, 0 아래는 0)에서 뽑아 같은 헝가리안·같은 술어로 센 수 | 개 |

- **단측**: 대립가설은 "관측이 같은 추정 수의 무작위 깊이보다 ±0.30 m 안 짝이 많다"이다. 동률($n^{(k)}_\text{pass}=n_\text{pass}$)은 관측에 불리하게 센다(코드 `baseline_p` = `mean(pass_b_values >= pass_b)`, 같은 분모라 정수 비교와 같다).
- $p<0.05\iff\#\{k:n^{(k)}_\text{pass}\ge n_\text{pass}\}\le49$.

### 2-4. 절대 목표

$$n_\text{pass}\ \ge\ n_T=\lceil T\,N_g\rceil=\lceil0.25\times388\rceil=97$$

**$T$ = 0.25, $n_T$ = 97로 고정한다**(사용자 결정 D1, 2026-11-07, 근거 §8). $0.25\times388=97$로 정수라 올림이 값을 바꾸지 않는다. 판정은 정수 비교 $n_\text{pass}\ge97$로 한다(판정률 B 소수 비교를 쓰지 않음). 참고로 다른 $T$의 정수 문턱은 0.30 → 117, 0.40 → 156이었다(채택 안 함).

### 2-5. U-3 합격과 판정 문구 (확정)

$$\text{U-3 합격}\iff p<0.05\ \wedge\ n_\text{pass}\ge97\qquad(\text{곧 } k\le49\ \wedge\ n_\text{pass}\ge97,\ k=\#\{k':n^{(k')}_\text{pass}\ge n_\text{pass}\})$$

판정 문구는 아래 네 개 가운데 하나를 **그대로** 쓰고 … 자리에 summary·matches csv의 값만 넣는다. $k$는 `baseline_p`×1000(정수), 기준선 평균·분위는 `baseline_pass_b_mean`·`_p025`·`_p975`(주 조합 행)다.

### 2-6. 미리 알아 둘 성질 — 활동 범위 기준선이 강하다

- 기준선은 활동마다 관측과 **같은 짝 수**($\min(n_{e,a},n_{g,a})$)를 만든다. 그래서 $p$는 사실상 짝 기준 판정률 $A$를 기준선의 $A$와 비교한다.
- M2-8([M28] 주 결과 첫 행)에서 기준선 판정률 B 평균 0.3973·97.5 % 0.4072, 짝 162개였다. 짝 기준으로 바꾸면 기준선 $A$는 평균 $0.3973\times388/162=0.95$, 97.5 % 분위 0.975다. 활동 안 정답이 0.6 m 범위 안에 몰려 있으면 범위 안 균등 난수도 가장 가까운 정답과 ±0.30 m 안에 들기 쉽다([M28] 원인 4).
- 따라서 이번에도 구조가 같다면 $p<0.05$는 관측 짝의 약 96–97 % 이상이 ±0.30 m 안이어야 성립한다. M2-8의 관측 $A$는 0.636이었다. 메타 εr 불확도(실측 보증 없음, 15 %면 깊이 0.7 m에서 약 ±0.05 m), 영점 띠 편향(−4~+3 cm, 실측 파형 상한 11–13 cm), 상단·중심 차(반경)만으로도 일부 짝은 0.30 m를 넘을 수 있다.
- 이 성질은 판정 기준을 바꾸는 근거가 아니라 결과를 읽는 근거로 등록한다(사용자 결정 4: "정답 범위를 아는 유리한 기준선 — 이기면 의미가 있다").
- **사용자 결정 D5(2026-11-07): 활동 범위 기준선 $p<0.05$ 조건을 유지한다.** 사용자는 이 기준선이 짝의 약 95 %를 맞힐 만큼 강해 **$p$ 조건 때문에 불합격할 가능성이 높다는 것을 알고** 유지했다. 전역 범위 기준선 $p$(S8)·게이트 $p$(S6)로 바꾸지 않았고, 결과를 본 뒤에도 바꾸지 않는다(§5).

## 6. 결론이 뒤집히는 경계와 보고 방식 (f)

| 경계 | 정의 | 보고 방식(판정은 바꾸지 않음) |
|---|---|---|
| $p$ 몬테카를로 경계 | 기준선이 관측 이상인 시행 수 $k$가 **37–64**/1,000(이항 Clopper–Pearson 95 % 구간이 0.05를 포함) | 판정은 점값 $p=k/1000$으로 한다($k\le49$면 $p<0.05$). "p 경계(몬테카를로 불확도 안)"와 구간을 함께 적는다. 시행 수·시드를 바꿔 다시 계산하지 않는다 |
| 절대 목표 표본 경계 | $\lvert n_\text{pass}-n_T\rvert\le9$ (판정률 0.25–0.30에서 이항 1 SE $=\sqrt{B(1-B)/N_g}\,N_g\approx8.5$–$9.0$개) | "목표 경계(표본 오차 안)"라고 적는다 |
| 보조 조합 뒤집힘 | 중심 가정, est·act 영점, X 포함, `keep_one`, `drop_all`에서 U-3 결론(두 조건 적용)이 주 조합과 다름 | 해당 조합을 목록으로 적는다("결론 뒤집힘 단서"). 중복 민감도는 기준선 200회라 $p$ 경계는 $k$ 4–16/200이다. 2 %p 단서(§4 항목 9)는 따로 적는다 |
| 상한에 막힘 | $n_\text{pairs}<n_T$ (추정 수가 적어 $A=1$이어도 목표 미달) | "목표가 추정 수 상한에 막힘"으로 원인 분해에 적는다 |
| 기준선 강도 | $p\ge0.05$이고 $A$가 기준선 $A$보다 낮지 않으나 97.5 % 분위 아래 | §2-6 성질로 설명하고, 게이트 지표(S6)를 함께 적는다 |

- $p$ 경계 처리는 사용자 결정 D6 (가)다: 점값으로 판정하고 경계 표시만 한다. 시행 수를 늘리거나 시드를 바꿔 다시 계산하지 않는다.

판정 결과 네 경우(확정 문구는 §2-5 표):
- **합격**: 두 조건 충족($k\le49$, $n_\text{pass}\ge97$).
- **불합격(기준선)**: 목표 충족, $p\ge0.05$($k\ge50$). 문구에 D5(불합격 가능성이 높음을 알고 유지한 기준선)를 적는다.
- **불합격(목표)**: $p<0.05$, $n_\text{pass}<97$.
- **불합격(둘 다)**: $k\ge50$, $n_\text{pass}<97$.
