### 1-2. 지표

$$
R=\frac{\sum_u c_u}{\sum_u L_u},\qquad
c_\text{lat}=20\log_{10}\frac{\mathrm{RMS}(q_\text{box, 가운데 절반 열})}{\mathrm{RMS}(q_\text{같은 행, 상자 옆 열})},\qquad
coh=\frac{\overline{(\bar q_\text{행})^2}}{\overline{q^2}}
$$

| 기호 | 뜻 | 단위 |
|---|---|---|
| $u$ | 정답 × fold 단위 | – |
| $c_u$ | conf > 0.25 박스 합집합이 정답 구간 $[i_0,i_1]$에서 덮은 트레이스 수(기본은 러너 정의: `pipe_band`, 시간 겹침 ≥ 정답 높이 50 %) | 트레이스 |
| $L_u$ | 정답 길이 $i_1-i_0+1$ | 트레이스 |
| $q$ | L1 회색값 − 내용 영역 회색 중앙값(AIHub는 crop 중앙값) | 회색 단계 |
| $c_\text{vert}$ | 분자는 같고 분모는 같은 열의 상자 위·아래 2 상자 높이(얕은 위치에서는 영점 띠가 분모에 들어가 음수로 치우친다. 그래서 주 비교는 $c_\text{lat}$로 한다) | dB |
| $c_\text{lat}$ | 상자 행에서 상자 옆(양쪽 각 1 상자 폭, 주입 띠는 테이퍼 밖) 대비 | dB |
| $coh$ | 상자 안 수평 일관성(평평한 띠 1, 질감만 약 0.02–0.3) | – |
| P | 측선 주기 $P_\text{line}$(배경 측선 값, `period_bg_samples`) | 샘플 |
| 깊이 | (꼭짓점 샘플 − 배경 영점 $k_z$) / P | P |
| y1 | 정답 박스 위 끝의 L1 행(plan 축척, 주기 바뀐 실현은 약간 다름) | px |

- 단순 합 $R$은 P4 정의(셀 같은 가중)와 조금 다르다. 전체에서 0.0653 대 0.06525다. 칸별 비교는 단순 합으로 낸다.

## 3. P4 판정·R3 보고 해석에 미치는 영향

1. **P4 판정(`no_effect`, `recall_delta` 0.0 %p)은 그대로다.** 노출 0과 R 안 제거 0은 검출 수준과 무관한 구조 결과이고, 재현율 재집계가 러너 값과 단위별로 일치한다.
2. **P4가 실제로 본 표본은 좁다.** R 박스 495개의 덮인 길이 68 %가 "길다·깊다" 27위치(14측선)에서 나온다. 이 위치들은 PP 위험 구역(영점 근처 PP-d, 기록 끝 PP-a·b)과 멀다. 그러니 "P4가 S3의 주된 위험을 볼 수 없다"는 공개 2를 데이터로 한 번 더 확인한 셈이다. 상한 16.1 %(0/21측선) 해석도 그대로다.
3. **`recall_pre` 6.5 %는 "IDS 종배관 재현율"의 추정이 아니다.** 배치 분포(위치 59 %가 AIHub 띠 위치 위, 63 %가 AIHub 띠 길이 아래)와 SNR 사다리의 가중 평균이다. 4TU P6 값(0.6–2.3 %)은 배치가 더 얕아서(4TU A0 y1 중앙 30 px, 깊이 3.7 P) 더 낮다. 실측 종배관 재현율의 하한이나 상한으로 옮기지 않는다.
4. **주입 진폭 축척(SNR 정의)은 고칠 대상이 아니다.** 12–18 dB 띠는 검출기 입력에서 학습 띠보다 이미 뚜렷하다. SNR 정의를 바꾸면 쌍곡선과의 짝지음만 깨진다([EMR] C3-2).
5. **주기 변화 140실현은 R3 재현율 해석을 바꾸지 않는다**(§2-5).

## 4. ③(E3 확장) 설계에 넘길 시사점

1. **위치를 요인으로 고정한다.** 무작위 배치 대신 정답 위 끝 L1 행(또는 영점 아래 P)을 구간(예: < 37 / 37–57 / 57–79 / ≥ 79 px)으로 정한다. 모델마다 같은 구간에 넣어 모델 효과와 위치 효과를 가른다. 이번 자료에서 M01·M17의 0은 모델이 아니라 얕은 위치 탓이었다. 구간마다 최소 위치 수를 미리 정한다. 깊은 구간을 채우려면 IDS 긴 시간창(≥ 40 ns) 측선이 필요하다(4TU 50 ns 기록·A0는 얕은 쪽에 몰림).
2. **px 위치와 P 깊이를 가르는 진단(선택)**: 같은 주입 실현을 L1 P* 6과 P* 약 4.2 px(AIHub 띠 crop 주기)로 각각 영상화한다. 재현율이 px 행을 따르면 절대 위치 사전이고, P 깊이를 따르면 물리 깊이 사전이다. 레시피 변경이라 판정 경로가 아니라 보고 전용 진단으로 둔다.
3. **SNR**: 쌍곡선은 6/12/18 dB에 30 dB 진단을 유지한다(E3 원안, 30 dB AGC 포화). 띠 항목을 넣는다면 18 dB까지 포화가 없으므로 24 dB를 더해 포화점을 확인한다. 대비 지표 $c_\text{lat}$·$coh$를 주입 전 단계에서 기록해 SNR 단계 간 시각 대비를 보고한다.
4. **띠 길이·테이퍼**: 길이는 AIHub 범위(≥ 12.4 P, L1 약 75 px 이상)이면서 $L/W_\text{eff}$ ≤ 0.45로 둔다. W 301에서 L 약 75–136트레이스다. L 150(갈림점, 반대 극성 유령)은 "약한 띠" 사례로만 따로 둔다. 끝 테이퍼는 프레넬 규칙을 유지한다.
5. **쌍곡선 E3의 테이퍼 짝**은 원안대로 같은 위치에서 개구 테이퍼 유무를 짝짓는다. 이번 결과는 위치가 큰 혼입 요인임을 보였으므로 짝은 반드시 같은 위치·같은 SNR에서 만든다.
6. **점수 기록**: 정답 사각형 안 최고 점수를 conf 0.001까지 남긴다. 이번 R3는 conf > 0.25만 남겨 "약하게 봤다"(H3)를 판정하지 못했다.
7. **(선택, H7) 띠 질감 변형**: 실제 종배관 반사는 측선을 따라 진폭이 흔들린다. 매설 깊이 기복, 측선–관 축 가로 어긋남(띠가 약 $y^2/(2d_c)$만큼 깊어짐), 토양 불균질 때문이다. 트레이스별 진폭 변조(예: 상관 길이 수 P, 표준편차 2–3 dB)를 보고 전용 갈래로 두면 $coh$ 0.9 대 0.28의 몫을 볼 수 있다. 근거가 추정이므로 주 결론의 조건으로 쓰지 않는다.
