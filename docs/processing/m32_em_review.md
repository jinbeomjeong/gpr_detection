## 1. 실측 배경 주입(M3)의 물리 타당성

### 1-1. 무엇이 정확하고 무엇이 근사인가

- **정확한 부분**
  - gprMax 모델은 선형이다. 그래서 같은 격자의 관 단독 응답 $d=u_\text{full}-u_\text{bg}$는 관이 만든 산란장 전체다. 여기에는 관–지표 다중 반사도 들어 있다.
  - 거울 대칭(꼭짓점 기준 트레이스 $i$와 $2i_a-i$)의 최대 차이는 꼭짓점 피크 대비 **6.7e-6–1.2e-4**다(깨끗한 M·K7 모델 24개). Tx–Rx가 바뀌는 거울 배치가 상반성으로 같은 응답이라는 뜻이다. 그래서 관 단독 응답의 위치·주행시간은 믿을 수 있다.
- **근사인 부분**: 실측 배경 $B$에 $d$를 더하면 $B$ 안의 실제 불균질과 관의 상호작용이 빠진다. 빠지는 것은 관 아래 반사층의 그림자, 실제 층과 관 사이 다중 반사다. 검출용 모양·위치 시험으로는 받아들일 만한 1차(Born형) 근사다. 성립 범위는 1-3에 적었다.

### 1-2. 진폭 축척 — 장비 이득·안테나 차

- 2D 합성의 진폭 단위(V/m, 선원 기준)와 실측 int16 계수는 이어지지 않는다. **절대 진폭을 맞추려 하지 말고, [PL] §3처럼 국소 SNR 사다리로 정하는 것이 맞다.** 다만 정의를 하나로 고정해야 한다. 아래를 제안한다.
  - 신호 $A$: 주입 관 단독 응답에 검출 갈래 앞의 **선형** 단계(DC·dewow·대역통과 (1)–(3))를 걸고 잰 꼭짓점 트레이스의 포락선 피크.
  - 잡음 $\sigma$: **배경만으로** 피팅 갈래 (1)–(4)(median 301)를 거친 단면에서 잰 RMS. 창은 꼭짓점 시각 ± 1 $P_\text{line}$이고, 트레이스는 주입 반폭(−6 dB) 안이다.
  - SNR = $20\log_{10}(A/\sigma)$. median은 비선형이므로 신호 쪽에는 걸지 않고 배경으로만 $\sigma$를 잰다.
- 사다리 0/6/12 dB는 위쪽이 낮다. 기준선 차이가 SNR 바닥에 묻히지 않게 **18 dB**("뚜렷함" 기준점)를 더하기를 권한다. 사다리 값은 측정 전에 커밋으로 고정한다.
- 실제 꼭짓점 SNR이 사다리 어디에 놓이는지 확인하려면 [D3] K 묶음 41꼭짓점에서 같은 정의로 재면 된다. 이 값은 **보고만** 하고 사다리 선택에 쓰지 않는다([PL] §6 Q1 (a)와 같은 원칙).
- **장비 시간 가변 이득**: 4TU 원시에 취득 이득 곡선이 들어 있는지는 기록이 없다.
  - 국소 SNR은 꼭짓점 시각의 이득만 흡수한다. 날개(늦은 시각)의 상대 진폭은 합성의 감쇠를 따른다.
  - 그래서 기본은 "이득 없음"으로 둔다. 감도 시험이 필요하면 배경 RMS의 시간 추세를 꼭짓점 시각에서 1로 정규화해 곱하는 변형을 보조로 둔다. 이 변형은 원시 시간 추세가 이득이라고 가정한다.
- **2D → 3D 진폭(필수 아님, 권장)**
  - 2D TMz는 선원이 선(line)이다. 그래서 기하 확산이 $r^{-1/2}$이고, 3D 점원·원통은 $r^{-1}$에 가깝다. 같은 꼭짓점 진폭에서 **2D 날개가 3D보다 $\sqrt{t/t_a}$배 강하다.**
  - 측정: 지면결합 모델의 날개 반폭(−6 dB)은 0.40–1.10 m다(M14 0.40, M01 0.52, M02 0.86, 상단 1.0 m 이상 모델은 개구 반폭 1.10 m에 닿음).
  - 2.5D 정지 위상 근사로 바로잡을 수 있다: 시각 가중 $\sqrt{t_a/t}$($t$는 송신 피크 기준), 스펙트럼 $\sqrt{-i\omega}$. 스펙트럼 항은 1-3의 파형 맞춤 필터에 흡수되므로 따로 걸 필요가 없다. 시각 가중만 남는다.
- **안테나 방사 패턴**: 차폐 보우타이의 지향성은 날개를 더 약하게 만든다. 2D에는 이것이 없다. 위 시각 가중과 같은 방향의 오차이므로 따로 모델링하지 않는다. 한계로만 적는다.
- **극성**: 실측 장비의 수신 극성 규약은 모른다. 주입은 **±1 두 극성을 짝으로** 넣고 극성별 재현율을 따로 보고하기를 권한다.
  - 관/지표 반사의 상대 부호는 물리로 정해진다. PEC·고유전 관은 공기→토양 지표 반사와 같은 부호이고, PVC-공기 관은 반대 부호다. 하지만 4TU 지표 띠는 직접 결합과 지표 반사가 합쳐진 사건이라 그 띠의 부호로 기준을 잡을 수 없다(`depth_physics.md` §7-2 E2). 기존 판단(부호가 있는 최대 엽 극성은 반사 부호 지표로 믿을 수 없음)과도 같다.
  - [PL] §2-2의 M3(전체 극성 반전 $255-q$)은 데이터셋 단위 규약을 바꾸는 진단이다. 띠와 관의 상대 부호를 유지하므로 물리적으로 유효한 진단이다.

### 1-3. 파형·중심 주파수 맞춤 — [PL]에 없는 필수 단계

측정값(`m32_em_review_checks.json`, 관 단독 응답 기준):

| 묶음 | 지배 주기 (ns) | 꼭짓점 포락선 FWHM (ns) |
|---|---|---|
| 400 MHz, h 0 (M01–M10, M17, M19) | 2.02–2.43 | 1.95–2.09 |
| 400 MHz, h 0.1 (M12, M15, M18) | 2.42–2.67 | 1.97–2.02 |
| 500 MHz, h 0.1–0.3 (M13, M20, K7 단일관 4개) | 1.50–1.99 | 1.57–1.73 |
| 4TU 실측 Δt 0.098 / 0.195 측선 $P_\text{line}$ ([PL] §1-4) | 2.51 / 2.94 (p50) | 꼭짓점 반사 2.9–3.8 ([FX] 표 1) |
| 광저우 IDS 400 MHz 30 / 50 ns 창 ([CV] 가정) | 2.93 / 2.11 | – |

- 주기는 400 MHz·h 0.1 모델이 4TU Δt 0.098 측선과 −4 ~ +6 % 안에서 맞는다. 500 MHz 모델은 21–40 % 짧다. Δt 0.195 측선(2.94 ns)과는 400 MHz·h 0.1도 9–18 % 짧다.
- **포락선 폭이 더 큰 문제다.** 실측 꼭짓점 반사는 1.5–2배 길다(링잉). 그대로 넣으면 주입 쌍곡선이 실제 관보다 주기 수가 적고 깨끗하게 보인다. 그러면 M3가 실제 관보다 쉬운 대상을 재게 된다.
- **권고 — 파형 교체 필터.** 선원 파형 교체는 선형 계에서 정확하다. 모든 트레이스에 같은 필터 $H(f)$를 곱하는 것은 선원 스펙트럼을 바꾸는 것과 같기 때문이다.
  - $H(f)=|W_\text{tgt}(f)|\,/\,(|W_\text{syn}(f)|+\epsilon\max|W_\text{syn}|)$, 영위상, $\epsilon$ 0.02–0.05.
  - $W_\text{syn}$: 합성 꼭짓점 트레이스를 꼭짓점 ± 3 P로 창을 씌운 뒤의 스펙트럼.
  - $W_\text{tgt}$: Gabor(가우스 포락 × 반송파). 반송파는 $1/P_\text{line}$(측선마다 이미 재는 값)이다. FWHM은 $k\,P_\text{line}$이고 $k\in\{0.8, 1.3\}$의 두 갈래로 둔다. 0.8은 Ricker형(합성 1.97/2.42 ≈ 0.81)이고, 1.3은 실측형(4TU 2.9–3.8 / 2.51 = 1.16–1.51)이다. 두 갈래를 따로 보고하면 파형 길이에 대한 감도도 함께 나온다.
  - 이 $k$ 값은 4TU 깊이 정답이 아니라 이미 잰 파형 폭에서 왔다. 레시피 선택 목적함수에도 들어가지 않는다. 그래서 Q1 (a) 원칙과 충돌하지 않는다. 다만 출처는 판정서에 적는다.
  - 통과 확인: 필터 뒤 `measure_period_samples` 주기가 $P_\text{line}$의 ± 5 % 안이어야 한다. 어긋난 모델·측선 쌍은 주입하지 않는다.
  - 2D 고유의 $\omega^{-1/2}$ 스펙트럼 기울기와 −45° 위상도 이 필터가 진폭 쪽을 흡수한다. 위상은 남지만, 극성 짝 주입(1-2)이 반사 부호 불확실성과 함께 덮는다.
- **리샘플**
  - 시간: 필터 → 목표 나이퀴스트의 0.8 아래 저역통과 → 실측 dt로 FFT 리샘플. 부표본 이동은 위상 이동으로 한다. 합성 dt 0.0118 ns(일부 0.0059)와 4TU 0.098·0.195, 광저우 0.0586·0.0977은 정수비가 아니다.
  - 공간: 4TU dx 0.02 m는 합성과 같아서 보간이 필요 없다. 광저우 0.024 m는 **보간하지 말고 dx를 다시 붙이기를 권한다**(합성 트레이스 간격을 0.024 m로 읽음).
    - $t(x)=\tfrac{2}{v}\sqrt{d^2+(x/1.2)^2}=\tfrac{2}{1.2v}\sqrt{(1.2d)^2+x^2}$이므로, 속도 1.2v·깊이 1.2d 모델과 운동학적으로 같다(εr 9 → 6.25). 원통이면 반경도 1.2배가 된다.
    - [PL] §3은 이미 "곡률은 메타 εr과 맞출 필요가 없다"고 했다. 그러니 dx를 다시 붙이는 쪽이 보간보다 안전하다. 기울어진 날개를 선형 보간하면 진폭이 깎인다. 정답 박스는 L0에서 정확하다. 유효 εr은 기록한다.

### 1-4. 공기결합(4TU) 높이·지표 반사 처리

- **지표 반사는 주입체에 없다.** $u_\text{full}-u_\text{bg}$를 빼면 합성의 직접 결합·지표 띠가 정확히 사라진다. 그래서 띠가 두 겹이 될 걱정은 없다. 실측 띠는 배경 쪽에 그대로 남는다. 옳은 처리다.
- **시간 맞춤 기준을 정해야 한다([PL]에 없음).**
  - 4TU(공기결합): 합성 배경 트레이스(`_bg`)에 같은 (1)–(3)을 걸고 띠 포락선 피크 시각을 잰다. 이 시각을 실측 측선의 영점(깊이 규약의 단일 띠 포락선 피크, 두 사건 측선은 첫 사건)에 맞춘다.
  - 광저우 IDS(지면결합): 합성 직접파 포락선 피크를 실측 직접파 포락선 피크에 맞춘다.
  - 이렇게 하면 꼭짓점과 띠 사이 간격이 합성 깊이와 일치한다. 정답 박스는 합성 꼭짓점 시각 + 이동량으로 L0에 정확히 놓인다.
- **트레이스별 높이 변화**: 측선 안에서 실측 띠 시각이 지형·거치 흔들림으로 바뀌면, 실제 관 반사도 공기 경로 $2\Delta h/c$만큼 같이 움직인다(1차 근사). 그래서 띠 시각 편차를 매끄럽게 한 값으로 트레이스마다 이동하기를 권한다. 보조 변형으로 둬도 된다.
- **h 선택**: 2절을 본다. 4TU는 h ≲ 0.1 m(E1 조건부)이고, h ≥ 0.3 m는 배제된다.
- **포화 — 계획에 없는 제약**
  - 4TU 원시 759측선 중 **471측선에 ±32767 포화 표본이 있다**(int16을 int32로 올린 뒤 |D| ≥ 32767). 측선 비율(그 측선의 포화 표본 / 전체 표본)은 포화가 있는 471측선 기준으로 p50 7.2e-4 / p95 5.0e-3 / 최대 7.7e-3이다. 759측선 전체(포화 없는 측선 0 포함) 기준이면 p50 1.1e-4 / p95 4.4e-3이다. 포화 표본의 마지막 위치(471측선)는 p50 51 / p95 71 / 최대 115 샘플(Δt 0.098에서 약 5.0 / 7.0 / 11 ns)로 띠 영역이고, 100 샘플 뒤까지 포화가 있는 측선은 4개다.
  - 포화는 비선형이라 그 구간에서는 선형 중첩이 깨진다. 규칙: **측선마다 마지막 포화 표본 + 2 $P_\text{line}$보다 이른 꼭짓점은 주입하지 않는다.**
  - 광저우 IDS 400 MHz는 391측선 중 148측선에 포화가 있다(가공본 색인 `saturated_ratio`; 148측선 기준 p50 2.6e-4 / p95 1.4e-3 / 최대 1.3e-2, 391측선 전체 기준 p95 1.0e-3). 같은 규칙을 쓴다.
  - 두 집계 모두 `m32_em_review_checks.py` Part T이고, 결과는 `.json`의 `saturation`에 있다.
  - 주입 뒤 합이 int16 범위를 넘으면 그 표본은 다시 자르지 말고 해당 주입을 기각한다. 18 dB 이하에서 띠 밖이면 넘지 않는다.

### 1-5. 개구와 시간창 — 계획에 없는 처리

- **개구 끝 잘림**: 관 단독 응답이 개구 끝 트레이스에서 얼마나 남는지(끝 트레이스 피크 / 꼭짓점 피크)를 쟀다.
  - 지면결합 M 세트(개구 2.2 m): 0.04–1.16이다. 깊이 1.0 m 이상(M03 0.68, M04 1.16, M16 1.09)은 날개가 개구에서 끊긴다.
  - 공기층 h 0.1 모델: 0.003–0.10으로 작다. M13(εr 4)만 0.54다.
  - 끊긴 날개를 실측 측선(중앙 235트레이스 = 4.7 m)에 넣으면 인공 끝(수직 경계)이 생긴다. **양 끝 0.2 m 코사인 테이퍼를 필수로** 하고, 테이퍼 구간은 정답 박스 폭 정의에서 뺀다.
- **시간창 끝**: 대부분 모델은 1 % 에너지가 시간창 끝까지 남아 있다(`last_1pct_energy_ns` ≈ 시간창). 합성 시간창은 29–62 ns이고 4TU는 50 ns 또는 100 ns다.
  - 합성 시간창 끝에서 1 P 코사인 테이퍼를 건다.
  - 꼭짓점 + 날개(테이퍼 전 개구) 시각이 합성 시간창 − 1 P 안에 드는 모델·위치만 쓴다.
  - Δt 0.195(100 ns) 측선의 깊은 위치는 기존 합성으로 채울 수 없다(§4 INJ-A 깊은 묶음).

### 1-7. 선형 중첩이 성립하는 범위 (정리)

1. **매질·장비 선형**: 토양·관은 GPR 출력에서 선형이다. 성립한다.
2. **넣는 위치**: 전처리 전 L0에 넣는다. 성립한다. 배경 제거·gain·클립·채움이 모두 주입체에 작용하므로 M3의 취지에 맞다.
3. **포화 밖**: 1-4 규칙을 지킨다. 띠 영역은 제외한다.
4. **상호작용 무시가 괜찮은 곳**: 꼭짓점이 실측 띠 + 2 P보다 깊다. 실측 강반사층과 수직으로 1 P 넘게 떨어져 있다. 실측 쌍곡선 후보([D3] K 묶음, `fourtu_apex_candidates_v1.csv`)와는 가로로 주입 반폭(−20 dB) 넘게 떨어져 있다. 이 밖에서는 그림자·다중 반사가 빠진다.
5. **이득을 모를 때**: 꼭짓점 SNR만 정확하다. 날개 상대 진폭은 합성(2D) 감쇠를 따른다(1-2).
6. **2D 한계**: 관이 측선과 직각일 때만 운동학이 맞는다. 비스듬히 만나면 쌍곡선이 $1/\sin\theta$배 넓어진다. 필요하면 x를 늘려 흉내 낸다(무한 원통에서 운동학적으로 정확하다). 진폭·편파는 근사다.
7. **MALA 처리본**: 이미 비선형 처리(배경 제거·gain)가 끝난 자료라 원시 의미의 중첩이 아니다. Q9 (b)의 "압축 측선 배경에서의 검출 축척 시험"에만 쓴다. B·G 레시피 비교에는 쓰지 않는다([PL] §4-2와 같은 결론).

## 2. 공기결합(4TU) 관 응답 모델

### 2-1. 높이 범위

- `depth_physics.md` §7-2 E1(조건부): 4TU 날개는 지면결합만큼 가파르다. h ≳ 0.1 m이면서 εr ≈ 9인 경우를 배제하고, h ≥ 0.3 m는 배제한다.
- **이번 측정으로 높이가 주입 모양을 크게 바꾼다는 것이 확인됐다.**
  - 같은 관(PEC OD 0.2, 상단 0.6 m, εr 9, 400 MHz)에서 날개 가시 반폭(−6 dB / −20 dB)은 h 0(M02) 0.86 / ≥ 1.10 m, h 0.1(M12) 0.48 / 0.74 m다.
  - K7(500 MHz, h 0.1, OD 0.1, 0.6 m)은 0.42 / 0.66 m다.
  - 원인: 공기→토양 굴절 원뿔(임계각 $\arcsin(1/\sqrt{\varepsilon_r})$, εr 9에서 19.5°, εr 16에서 14.5°) 밖으로 나간 날개가 근접장으로만 이어진다. εr 4인 M13은 30°라 날개가 남는다(끝/꼭짓점 0.54).

### 3-2. 판단

1. **안테나 추정: 250 MHz급 RAMAC가 가장 그럴듯하다(추정).**
   - Δt 0.391 ns는 표본화 2.56 GHz다. RAMAC는 보통 안테나 주파수의 약 10배로 표본화한다. 시간창 약 190–200 ns도 250 MHz 안테나의 일반 설정이다.
   - 지면결합 차폐 안테나의 수신 지배 주파수는 공칭보다 10–30 % 낮게 나온다. 폴더 중앙값 214–240 MHz(10.7–12.0 샘플)와 맞는다. 안테나 기록이 없으므로(.rad ANTENNAS 0) 확정은 아니다.
2. **한 안테나에서 물리적으로 나올 수 있는 폭은 약 ±30 %다.** 토양 하중에 따른 하향 이동과 깊이 감쇠에 따른 저주파 이동이 그 범위다. 측정 폭 4.45–36.6 샘플(8.2배, 폴더 0701 안에서만 6.9배)은 이 범위를 크게 넘는다. **물리 변동이 아니라 처리 잔여와 추정기 문제다.**
   - **36.6 샘플(70 MHz)**: 0701의 1측선이다. 250 MHz 안테나의 대역 밖이고, 늦은 구간 RMS가 이른 구간의 0.6 %인 폴더다. 배경 제거·dewow 뒤에 남은 저주파 잔여가 최대값을 잡은 것이다.
   - **6.0 샘플(427–429 MHz)**: 07011 다수, 0704·0806 일부. 213.75 MHz의 정확히 2배라 고조파(처리 링잉·클립) 또는 다른 안테나(500 MHz급)일 수 있다. 07011은 시간창(200 ns, 512 샘플)과 표본화가 다른 폴더와 같다. 500 MHz 안테나에 200 ns 창은 드문 설정이므로 고조파 쪽이 더 그럴듯하다(**추정**). 다만 이 측정만으로는 가르지 못한다.
   - **4.45 샘플(575 MHz)**: 07011 3측선. 뒤 1/3 주파수가 560 MHz이고, 늦음/이름 RMS 0.72로 gain이 걸려 있다. gain이 키운 늦은 고주파 잡음이 최대값을 잡은 것이다. 추정기 탐색 하한(4 샘플 = 640 MHz)에도 가깝다.
3. **결과 영향.** R-a(측선별 그대로)를 쓰면 같은 장비의 같은 물체가 측선마다 2–8배 다른 축척으로 L1에 들어간다. 주기를 250 MHz 가설(약 12 샘플)로 보면 $H_c=n_sP^*/P=484\cdot6/12\approx242$ px라 **대부분 압축되지 않는다**($P$ 10.67 샘플이면 $c$ 약 1.08로 범위 안). 즉 [PL] §2-6의 "MALA 75측선 전부 $c$ 1.45–2.7, 범위 밖"은 주기 추정 잔여의 결과일 가능성이 크다. Q9 대상 수가 R1 규칙에 달려 있다는 [PL]의 지적은 맞고, 그 크기가 75 ↔ 소수로 크다.

### 3-3. R1 규칙에 대한 EM 의견

- R-b(이른 창)와 R-c(폴더 중앙값)를 함께 쓰고, 물리 대역 제한을 더하기를 권한다.
  - 탐색 대역을 폴더 중앙값 주파수의 [0.6, 1.5]배로 묶는다. 고조파·저주파 잔여를 막기 위해서다.
  - 측정은 포락선이 잡음 바닥 위인 이른 창에서 한다.
  - 측선값이 폴더 중앙값에서 ± 30 %를 넘으면 폴더 중앙값으로 바꾸고 플래그를 단다.
- 07011처럼 폴더 전체가 다른 모드면 폴더 중앙값도 그 모드를 따른다. 그래서 "폴더 07011은 고조파인가"는 한 번 따로 본다. 스펙트럼에 213 MHz 근처 봉우리가 함께 있으면 고조파이고, 없으면 다른 안테나다. 이 확인은 gpr-processing-expert의 R1 진단 몫으로 넘긴다.
- MALA는 영점·$f_c$가 없고 처리본이다. 그래서 위 판단은 축척(검출 영상) 용도에만 쓴다. 깊이에는 쓰지 않는다.

### B-1. A0 날개가 개구 끝까지 퍼짐 — 물리적으로 가능하지만, 지금 값은 개구에 묶인 하한이고 박스 정의가 SNR과 따로 논다

  - 공기층이 없으면 굴절 원뿔 제한이 없다. 그래서 −20 dB 날개가 꼭짓점에서 1 m 넘게 이어진다. 기존 측정(§1-2·2-1)에서 M02–M11의 −20 dB 반폭은 개구 반폭 1.10 m 이상이었고, 2.5D 가중($x$ = 1.1 m에서 약 −2.7 dB)을 걸어도 개구 안에 남는다.
  - 실측과 비교: 4TU에서 검출된 쌍곡선 박스는 p5/p50/p95 43/64/83.5 px, 즉 $P^*$ 6 기준 7.2/10.7/13.9 P다([D3] §2-2). 하지만 놓친 01.1 쌍곡선은 다리가 L1에서 약 100–135 px, 즉 17–22 P로 보였다([D3] §8-5, 육안 추정). 그러니 **16.6–21.4 P는 4TU에 실제로 있는 넓은 쌍곡선 범위**다. 다만 AIHub 박스 분포(p95 14.67 P)와 검출된 4TU 박스보다 넓은 쪽 꼬리다.
  - IDS의 보이는 쌍곡선 폭은 잰 자료가 없다.
- **인공물인 부분 두 가지**
  1. **개구 제한**: `wing_box`가 합성 개구(2.2 m, 111트레이스) 전체를 덮는다. 16.6–21.4 P는 2.2 m를 측선 $\delta_z$(εr 9에서 1 P = 0.1255 m)로 나눈 값의 범위와 맞는다. 실제 −20 dB 폭은 이보다 넓을 수 있으니 **이 값은 하한**이다. 날개가 개구 끝에서 잘린 쌍곡선이라는 뜻이기도 하다.
  2. **정의**: 잡음 없는 단위 응답의 −20 dB는 사람이 보는 폭보다 넓다. 사람은 신호가 잡음 위인 곳까지만 본다. 국소 SNR $s$ dB로 넣으면 꼭짓점 대비 $10^{-s/20}$ 아래 날개는 잡음에 묻힌다. 0/6/12/18 dB이면 꼭짓점 대비 0/−6/−12/−18 dB 지점에서 보이지 않게 된다. 지금 −20 dB 박스는 18 dB에서만 보이는 폭과 비슷하고, 낮은 SNR에서는 보이는 폭보다 넓다.
- **수정 명세(gpr-processing-expert·cv 선택용)**
  - (a) 필수: −20 dB 성분이 개구 테이퍼 칸에 닿으면 `aperture_limited` 플래그를 붙인다. 그 폭은 하한으로 본다. 분포 층(`in_distribution`)에서는 "폭 미상(≥ 값)"으로 따로 센다.
  - (b) 권고: 정답 박스 문턱을 SNR에 맞춘 "보이는 범위"로 한다. 문턱 = $\max(10^{-s/20}, 0.1)$ × 꼭짓점 포락선(단위장 (1)–(3) 기준), 단 0 dB에서는 −6 dB로 둔다. 박스 규약 자체는 cv 몫이므로 이것은 물리 쪽 제안이다. 고정 −20 dB를 유지한다면, 낮은 SNR에서는 박스가 보이는 범위보다 넓다는 것을 판정서에 적는다.
  - (c) 선택: 넓은 쌍곡선이 분포 밖에 몰리는 것은 A0를 4TU에 쓸 때의 물리 결과다(h → 0 극한). A0와 A1을 따로 보고하는 원칙(§2-2)대로 두면 된다. A1(h 0.1)은 −20 dB 반폭이 0.66–1.20 m라 분포 안에 더 많이 든다.

  - 상단 1.0–1.1 m인 M18·K7_P1_D110_S002도 실패가 있다. 0건은 M03·M04·M15·M16·M19·K7_P1_D150_S003이다.
  - IDS도 얕은 모델(M01·M02·M05–M11·M14·M17)에 몰려 있다.
  - 계획 단계 실패는 주 k 1.3 기준이다(smoke에서는 k 0.8 쪽도 실패).
- **원인(재현 (ii))**: `measure_period_samples`를 패치 **전체**(모든 트레이스·모든 시각의 평균 스펙트럼)에 건다. 파형 교체 필터는 꼭짓점 ±3 P 창의 스펙트럼으로만 정규화된다. 그래서 창 밖의 늦은 성분이 평균 스펙트럼 피크를 끈다. 늦은 성분은 관–지표 다중 반사, 2D 꼬리, 큰 각도의 날개, 시간창 끝 부근이다.
  - 얕은 관일수록 이 성분이 기록 안에 많다. 깊은 관은 기록 밖으로 빠진다.

| 잰 영역 | 상단 ≤ 0.7 m 모델의 오차(P 2.51 / 2.94) | 상단 ≥ 1.0 m 모델 |
|---|---|---|
| 전체 단면(현재 구현) | −9.3 ~ +13.3 % (M02 +6.2/−6.1, M12 +6.2/+13.3, K7_P1_D060 +5.8/+13.3, M08 +6.2/−9.3) | −3.4 ~ +3.3 % (M18 +0.3/−3.4, K7_P1_D110_S002 +3.3/+0.3) |

- **판단**: 필터는 맞게 동작한다(부록 A, 1차 반사 영역 오차 ≤ 4 %). 실패는 검사하는 영역이 1차 반사 밖까지 넓어서 생긴다. ±5 %는 1차 반사 영역에서 여유 1 %p 이상으로 통과하므로 기준은 엄격하지 않다. 추정기의 주기 분해능은 약 0.6 %다(512 샘플, 8배 덧대기, P 약 25 샘플).
- **수정 명세**
  - 주기 확인을 **1차 반사 영역**에서 한다: 단위장을 −20 dB 날개 성분(`wing_mask`) 안, 시각 ≤ 꼭짓점 + $\tau_m$ − 1 P인 칸으로 제한한다. $\tau_m$ = 꼭짓점 시각 − 송신 피크(관–지표 왕복 시간)다. 기준 ±5 %는 그대로 둔다.
  - 물 찬 PVC(M08)는 이 영역에서도 ±6–8 % 어긋난다. 관 안 물층의 공진이라 실제 물관에서도 생기는 물리다. 기각하지 말고 `period_ringing` 플래그로 따로 보고하기를 권한다. M14·M18은 1차 반사 영역에서 통과한다(−1.9 ~ −0.8 %).

### B-3. int16_overflow — 원인은 꼭짓점 2.4–4.7 P 앞의 약 1 % 선행 성분, 포화 띠 위에서 기각된다

- **재현 (iii)**: 초과가 난 배치에서 측선마다 처음 400건(3측선 1,200건)의 최악 표본을 기록했다. 위치와 크기는 다음과 같다.
  - 위치: 꼭짓점보다 2.4–4.7 P 위(중앙 2.7–3.5 P), 즉 지표 띠의 포화 표본과 포화 직전 큰 표본이다. 최악 표본이 모두 정확히 ±32767은 아니다(32767 근처 포함).
  - 크기: 주입값/꼭짓점 주입 진폭은 중앙 0.24–1.25 %, 최대 1.5 %다. 국소 $\sigma$가 310–2,700 계수라 주입값은 최대 240 계수가 된다.
  - k 1.3 Gabor의 가우스 꼬리는 2 P 앞에서 1.4e-3, 3 P 앞에서 4e-7이다. 그러니 이 선행 성분은 파형 교체의 꼬리가 아니다.
  - 합성 관 단독 응답 자체에 1차 반사보다 먼저 오는 약한 성분(공기 측면파 등, 이전 측정에서 1–4 %)이 있다. 이 성분은 품질 문턱(에너지 1 % = 진폭 10 %)을 통과한다. 원인은 이것으로 본다(**추정**: 성분 분해는 하지 않았다).
- **SNR 의존**(배치 대비 초과 비율)

| 측선 | k 1.3: 0 / 6 / 12 / 18 dB | k 0.8: 0 / 6 / 12 / 18 dB |
|---|---|---|
| 010.14/Path3 | 13.5 / 14.0 / 14.2 / 14.5 % | 13.4 / 16.3 / 21.2 / 26.3 % |
| 010.15/Path1 | 15.5 / 18.6 / 19.4 / 19.4 % | 9.0 / 10.5 / 10.5 / 13.5 % |
| 01.2/Path4 | 16.7 / 16.7 / 17.2 / 17.8 % | 13.3 / 15.8 / 23.0 / 27.3 % |

  - SNR이 높을수록 늘어난다. k 0.8에서는 0 dB와 18 dB의 차가 약 2배다. 그래서 **SNR·k 짝지음이 깨진다**(같은 위치가 낮은 SNR에서는 받아들여지고 높은 SNR에서는 기각된다).
- **대안 평가**
  - 포화 행 근처 배치 제외: 선행 성분이 4.7 P 앞까지 있으므로 영역 (a)를 약 5 P로 넓혀야 한다. εr 9에서 약 0.63 m만큼 얕은 깊이를 잃는다. **권하지 않는다.**
  - 포화 표본 원값 유지: 수신기는 포화 표본에서 원래 값 + 작은 신호를 기록할 수 없다. 실제 띠 진폭이 문턱을 넘는 양을 모르므로, 주입량이 작을 때는 잘린 값을 그대로 두는 것이 가장 나은 물리 추정이다. 그 표본은 꼭짓점에서 2.4 P 넘게 위다. 정답 박스(k 1.3 포락선 −20 dB는 꼭짓점 ± 약 1.2 P)에 들지 않으므로 **정답에서 뺄 칸이 없다.** 배경 제거 뒤에는 띠 자체가 지워지는 영역이기도 하다.
- **수정 명세(권고안)**
  - 합을 int16 범위로 잘라 저장한다(`np.clip(sum, −32768, 32767)`, 원래 포화 표본은 원값 유지와 같다). 기각은 다음 경우만 한다.
    - (i) 잘린 칸이 정답 박스(`box`) 또는 −6 dB 반폭 SNR 창 안에 있다.
    - (ii) 잘린 칸의 주입값이 꼭짓점 주입 진폭의 5 %를 넘는다(실제 띠 겹침).
  - 잘린 칸 수와 최대 주입 비율을 정답 레코드에 남긴다.
  - 이렇게 하면 기각이 SNR과 무관해져 짝지음이 유지된다. 재현에서 최대 비율이 1.5 %였으므로 (ii)는 지금 자료에서 발동하지 않는다.
