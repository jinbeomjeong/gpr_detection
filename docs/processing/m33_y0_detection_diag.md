### 1-2. 지표 정의

관 단독 응답은 $a_\text{pipe} = a - a_\text{bg}$(가운데 bg 트레이스)이다. bg의 가로 변화는 최대 진폭 대비 $2\times10^{-6}$–$1.8\times10^{-5}$라서 토양이 가로로 균일하다고 볼 수 있다. 여기에 선형 단계(DC·dewow·밴드패스)만 통과시킨 포락선을 L1 격자로 면적 평균한다. 상자는 꼭짓점(정답 ±1 P, ±3 트레이스 안 최대)을 씨앗으로 한 연결 성분의 외접 상자다.

$$
w_\ell = \frac{c_1 - c_0 + 1}{P_{L1}},\qquad h_\ell = \frac{r_1 - r_0 + 1}{P_{L1}},\qquad
\Delta_\text{AGC} = 20\log_{10}\frac{F_\text{post}/A_\text{post}}{F_\text{pre}/A_\text{pre}}
$$

$$
L = \frac{1}{N_c-1}\sum_{c}\mathbf{1}\!\left[\operatorname{corr}(q_{:,c},\,q_{:,c+1}) < 0.5\right]\quad(\text{위 25행})
$$

| 기호 | 뜻 | 단위 |
|---|---|---|
| $P_{L1}$ | L1 영상의 주기(= $P_\text{line}$ / 세로 샘플·px) | px |
| $\ell$ | 포락선 수준(꼭짓점 대비) | dB |
| $c_0, c_1, r_0, r_1$ | 상자 열·행 경계 | px |
| $w_\ell, h_\ell$ | 상자 폭·높이 | 주기 P |
| $A_\text{pre}, A_\text{post}$ | AGC 전(배경 제거 뒤)·후 꼭짓점 포락선 | 진폭 |
| $F_\text{pre}, F_\text{post}$ | 영점 + 2 P 아래, 관 응답(−40 dB 지지 + 5샘플 팽창) 밖 RMS | 진폭 |
| $\Delta_\text{AGC}$ | AGC가 꼭짓점 대비 바닥을 들어 올린 양 | dB |
| $q$ | 회색 내용 영상(0–255) | – |
| $L$ | 인접 열 상관이 0.5 미만인 쌍의 비율(세로 기둥 무늬 지표) | – |
| AIHub 범위 | tpipe 라벨 p5–p95: 폭 7.79–14.67 P, 높이 5.22–8.35 P (`inject.py` `AIHUB_WIDTH/HEIGHT_PERIODS`) | P |

## 3. 같은 모델을 실측 배경에 넣었을 때 (H1과 H2의 분리)

M3-2 단계 C 사전 점검(r0, fold 0, 주 칸, 4TU + IDS 배경, conf 0.25)의 `pipe_hyperbola` 적중 수 / 주입 수:

|---|---|---|---|---|---|

| M17 | 84/170 | 141/170 | **317/340 (93 %)** | 149/170 | 0/1 / 0/5 |
| M01 | 13/104 | 51/104 | **149/198 (75 %)** | 70/104 | 0/1 / **1/5** |

| M10 | 8/50 | 19/50 | 44/98 (45 %) | 18/50 | 0/1 / 0/5 |
| M05·M06·M07·M08·M02·M19·M12 | | | 13–37 % | | 0/1 / 0/5 |
| M03·M04·M09·M15·M16·M18 | 0 | 0 | **0** | 0–1 | 0/1 / 0/5 |
| 전체(M01–M20 주입분) | 248/1058 | 463/1058 | 1053/1990 | 521/1057 | 0/20 / 3/100 |

(M13·M20은 이 사전 점검의 주입 목록에 없다. 원자료 `analysis/processing/m33_y0_vs_stagec_inject.json`.)

해석
1. **모델 고유 모양(H1)이 "검출 가능 여부"를 정한다.** 6모델은 실측 배경에서도 0 %다. 깊은 관(관 상단 6.7–16 P), 납작한 호, 짧은 측선(M09 εr 4, 측선 반폭 5.9 P)이 여기에 든다. 이 모델들의 Y0 0은 단독 측선 탓이 아니다. (§7-2 갱신: 이 대조는 fold 0만 본 것이다. E3에서 M03·M04·M16은 다른 fold에서 잡혔고, 모든 fold에서 0인 것은 M09·M15·M18뿐이다.)
2. **단독 측선(H2 + H3)이 나머지를 지운다.** 실측 배경에서 75–93 %인 M01·M14·M17이 단독으로는 5 fold에서 1·2·0이다. Y0 적중 모델은 주입 재현율 상위 모델의 부분집합이다(같은 순위).
3. 주입 쪽도 SNR 12 → 18 dB에서 재현율이 떨어진다(M01 75 → 67 %, M14 93 → 86 %, M17 93 → 88 %). 단계 C 판정서 §2의 AGC 포화 해석과 같은 방향이다. 단독 측선은 SNR이 무한대인 끝점이다. 배경이 없으면 AGC 창 RMS를 관 자신이 정하므로 날개가 꼭짓점과 같은 밝기가 된다(§2-1 전폭 20/20). 주입에서 쓴 개구 테이퍼도 없다. 그래서 단독 영상의 쌍곡선은 "가장자리에서 가장자리까지 고르게 밝은 아치 + 잔향 겹 호"가 된다. AIHub 라벨처럼 꼭짓점 주변만 도드라진 모양이 아니다.
4. 주입과 단독은 SNR·테이퍼·배경 질감·채움 모양이 함께 다르다. 그래서 이 대조만으로는 H2(질감)와 H3(AGC·채움) 몫을 따로 떼지 못한다. 분리는 §6 추론 실험이 필요하다.
5. (§7 갱신) 3의 "단독 영상에서 AGC가 날개를 들어 올려 안 보인다"는 해석은 E1에서 기각됐다. AGC를 꺼도 적중이 늘지 않는다. 날개 들림은 영상에 실제로 있지만, 검출을 막는 주 원인은 아니다.

## 5. 다음 검증에서 합성 자료를 다시 쓸 때의 권고

(2026-11-15 §7 반영 개정. 1·2·4를 고쳤고 7·8을 더했다.)

1. **단독 gprMax 측선을 r0 재현율 시험에 쓰지 않는다.** 관 응답(전체 − `_bg`)을 **실측 배경에 주입**하는 방식만 쓴다.
   - 근거: 공통 80칸 적중이 단독 0, 백색잡음 최대 10(18 dB), 실측 배경 37(12 dB)이다(§7-1).
   - 백색잡음 추가는 대용이 못 된다. 실측 배경의 4분의 1–3분의 1 수준밖에 회복하지 못한다.
   - AGC를 끄는 레시피(G4·G2)로 단독 측선을 살리려는 시도도 효과가 없다(E1).
2. **모델 선택**
   - 실측 배경에서 모든 fold·SNR에서 0인 M09·M15·M18은 검출 기반 게이트(G3류)의 분모에서 뺀다.
   - M03·M04·M16은 fold·위치에 따라 0–4/5로 흔들린다. 분모에 넣으려면 위치를 여럿 쓴다.
   - 안정적으로 정보를 주는 모델은 M10·M14·M17·M19(E3 12·18 dB에서 5/5 fold)와 M01·M07·M12(2–5/5)다.
   - 분포 안 판정은 −6 dB 폭이 아니라 **주입 경험 재현율**(여러 위치 × 5 fold)로 미리 고정한다.
3. **기록 끝 근처 관(Y1류)**: 기록을 자른 뒤 다시 처리하지 않는다. 전체 기록을 r0로 처리한 뒤 진폭을 자르거나, AGC 창을 원 기록에서 고정해 넘긴다. 주기 고정(이미 함)만으로는 부족하다. 지금 방식이면 창/기록 ≥ 0.8에서 세로 기둥 오검출이 생긴다.
4. **측선 길이·채움**: 2.2 m 측선은 L1에서 13–29 P라 타일 하나에 오른쪽·아래 L자 채움이 생긴다. 이것은 학습에 없던 모양이다. 효과는 작지만 0이 아니다(E4: 3 → 7). 주입 방식이면 실측 측선 폭을 쓰므로 저절로 풀린다. 단독 영상을 쓸 수밖에 없으면 내용을 가로 가운데에 둔다(학습 기본 모드와 같은 ㄷ자).
5. **점수 기록**: 합성 조건은 conf 0.001까지 꼭짓점 상자 최고 점수를 남긴다. 그래야 "0.25 아래로 약하게 봤다"와 "아예 못 봤다"를 가를 수 있다.
6. **영점 근처 관(PP-d 시험)**: 합성에 영점 바로 아래 관이 없다는 한계(판정서 §7-1 2)는 그대로다. 위 1–3을 지켜도 Y0는 PP-d 검정력을 주지 않는다.
7. **SNR 범위**: 실측 배경 주입에서도 30 dB에서 적중이 줄어든다(공통 80칸 37 → 25). 그래서 재현율 시험의 SNR 상한은 18 dB 근처에 두고, 30 dB 이상은 "AGC 포화 영역"으로 따로 보고한다.
8. **주입 위치 수**: 모델당 위치 하나로는 위치 효과와 모델 효과가 섞인다. 예를 들어 M01은 단계 C(여러 위치, fold 0) 75 %인데 E3 fold 0에서는 0이다. 모델당 4TU·IDS 여러 위치를 쓰고, 개구 테이퍼 유무는 같은 위치에서 짝지어 비교한다.

### 7-2. 가설별 판정

| 가설 | 판정 | 근거 (공통 80칸 기준) |
|---|---|---|
| H3-gain: AGC 날개 들림이 주 원인 | **기각** | G4 0, G2 0(E0 0). 전체 100칸에서도 2·1로 오히려 E0 3보다 적다. 짝 비교에서 얻은 칸이 0이다. 배경이 없을 때는 AGC를 어떻게 하든 영상에 관 말고 아무것도 없다 |

**해석**
- 단독 측선이 안 보이는 것은 AGC 때문이 아니다. **검출기가 관을 실측 배경 문맥 속에서만 쌍곡선으로 읽기 때문이다.**
- 일반 잡음은 이 문맥의 일부만 대신한다(E2 대 E3 = 10 대 34, 18 dB).
- E3과 E2 사이에는 배경 질감 말고도 지표 띠(직접파), 측선 폭(L자 채움 없음, 여러 타일), 4TU 주기 스케일이 함께 다르다. 그래서 H2b는 "실측 측선 전체 문맥"의 효과다. 질감만의 몫은 따로 떼지 못했다.
- E4가 채움 몫이 작다는 것을 보이므로, E3–E2 차이의 대부분은 질감과 지표 띠 몫으로 본다(추정).

### 7-3. 해석 결정 1–5의 타당성

| 결정 | 판단 | 이유 |
|---|---|---|
| 1. 타일 병합 뒤 L0 격자에서 꼭짓점 포함 판정, 클래스 무관 점수 병기 | **타당** | D0와 같은 규칙이다. E0가 D0와 100/100 일치하므로 경로가 같음이 확인된다. 클래스 무관 적중은 E3 12 dB 49, 18 dB 50으로 `pipe_hyperbola`(44·41)보다 5–9칸 많다. 다른 클래스로 읽는 경우가 일부 있다는 뜻이며, 결론은 바뀌지 않는다 |
| 2. G2·G4를 r0에서 gain만 바꿔 구성 | **타당** | 명세 그대로다. "창 8 P"는 AGC 창 8/$f_c$(`agc_window_periods` 8)라서 r0 창과 같고, 이득 모드만 바뀐다 |
| 3. E2: 관 단독 + 잡음, SNR = 꼭짓점 열 ±1 P 포락선 최대 / 잡음 RMS(둘 다 DC·dewow·밴드패스 뒤), 모델당 잡음 1개를 배율만 바꿈, 주기 E0 고정 | **타당** | 진폭비 dB이고 단계 C의 A/σ와 같은 종류라 비교할 수 있다. 같은 잡음을 배율만 바꾸므로 SNR 단계 사이가 짝 비교가 된다. 주기를 고정했으니 잡음이 주기 측정을 바꿔 영상 축척이 달라지는 혼입이 없다. 한계 2가지: (i) 백색잡음이라 수평 상관(지표 띠·층)이 없다. 이것이 E2와 E3의 차이를 만든 성분일 수 있다. (ii) 직접파가 없어 지표 띠가 없다. 둘 다 명세 의도("잡음 바닥만")와 맞는다 |
| 4. E3: 모델당 단계 C 첫 4TU 위치 1개, 이득·꼭짓점은 `inject_realization`, 테이퍼만 제거, int16 규칙 적용 | **타당, 단 위치 1개는 한계** | 같은 위치에서 SNR만 바꾸므로 SNR 비교는 짝 비교다. 반면 모델 간 비교에는 위치 효과가 섞인다. 예: M01은 E3 위치(011.17/Profile_6409)에서 fold 0 적중이 0인데, 단계 C(여러 위치) fold 0에서는 75 %다. 테이퍼를 걷으면 패치 끝(±1.1 m)에서 날개가 갑자기 끊긴다. 고 SNR에서 이 끊김이 보일 수 있으나, 30 dB 하락은 단계 C(테이퍼 있음) 18 dB 하락과 같은 방향이라 끊김 탓만은 아니다. int16 거부(M01·M14 30 dB)와 M17 클립(110–134칸)은 실측 기록기 포화 규칙과 같아 물리적으로 맞다 |
| 5. E4: 가로만 가운데, 위아래 이동 없음(ㄷ자) | **타당** | 학습 기본 모드(축소 시 위쪽 행 기준, 좌우·아래 채움)와 같은 모양이다. 영점이 위에 붙는 실측 L1과도 맞는다. 위아래로 옮기면 오히려 학습에 없는 위 채움이 생긴다 |

- **다시 돌려야 할 결정적 문제는 없다.** 결론(H2b ≫ H2a > H3-pad, H3-gain 기각)은 E0 대비 짝 비교(각 변형의 전체 기록)에서 얻음/잃음이 E3 12 dB 41/0, E2 18 dB 15/2, E4 4/0, G4 0/1로 갈린다. 공통 80칸 적중(37, 10, 4, 0)도 같은 순서다. 위치 1개 한계는 결론의 방향이 아니라 모델별 수치에만 영향을 준다.
- 선택적 보강(판정에 필요 없음): E3를 모델당 여러 위치(4TU 4 + IDS 4)로 넓히고 같은 위치에서 테이퍼 유무를 짝지으면 권고 8의 모델 선택표를 만들 수 있다. 필요해지면 메인 세션 권고로 다시 올린다.

### 7-4. E3 빈칸의 영향

| 빈칸 | 영향 |
|---|---|
| M13·M20(단계 C 표에 4TU 위치 없음) | 공기층 0.1·0.3 m 모델 중 두 개가 E3에 없다. 공기층 모델은 M12·M15·M18이 남아 있다. M12는 E3 12 dB 4/5, M15·M18은 0이다. 그래서 "공기층 모델은 배경이 있어도 약하다"(단계 C 4TU/A1 바닥값)는 이번 자료로 부분적으로만 확인된다. 단독(E0–E2, E4)에서 M13·M20은 모든 변형 0(E2 포함)이다 |
| M01·M14 30 dB(int16 거부) | 30 dB 전체 칸(25/80)에서 가장 잘 잡히는 두 모델이 빠져 30 dB가 낮게 보인다. 그러나 공통 집합에서도 12 → 30 dB 하락(37 → 25)이 있다. 두 모델이 30 dB에서 10칸을 다 맞혔다고 해도 35/90으로 12 dB 44/90보다 낮다. 그래서 고 SNR 하락 결론은 이 빈칸 때문이 아니다. 거부 자체는 "30 dB 관 + 이 배경이면 실측 기록기가 포화한다"는 물리적 사실이다 |
| M17 클립(110–134칸) | 꼭짓점이 평평하게 잘린다. 그래도 M17은 6–18 dB에서 5/5, 30 dB에서 3/5다. 클립이 늘어나는 30 dB에서만 줄어 포화 해석과 맞는다 |

## 8. 가정·한계

- 관 단독 응답은 bg 가운데 트레이스를 빼서 얻었다(가로 균일 가정, 근거 bg 가로 변화 ≤ $1.8\times10^{-5}$). median 배경 제거는 비선형이라, 상자는 선형 단계만 거친 포락선으로 쟀다.
- AIHub 범위는 라벨 상자(사람이 그림)이고 합성 상자는 포락선 수준 상자다. 정의가 달라 크기 비교는 경향으로만 쓴다.
- 단계 C 대조는 fold 0, r0, 사전 점검 칸만이다. 주입은 개구 테이퍼·유한 SNR·실측 측선 폭을 쓰므로 단독 Y0와 여러 조건이 함께 다르다(§3 4).
- 깊이 값(m)은 이 문서에서 쓰지 않는다(검출 진단 전용).
- §7은 fold 칸이 같은 영상을 공유한다(fold 간 독립 아님). E3는 모델당 위치 1개다. 통계 검정은 하지 않았고 짝 비교 개수와 모델 단위 수로만 판단했다.
