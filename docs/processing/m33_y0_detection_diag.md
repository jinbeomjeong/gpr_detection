### 1-2. 지표 정의

관 단독 응답은 $a_\text{pipe} = a - a_\text{bg}$(가운데 bg 트레이스)이다. bg의 가로 변화는 최대 진폭 대비 $2\times10^{-6}$–$1.8\times10^{-5}$라서 토양이 가로로 균일하다고 볼 수 있다. 여기에 선형 단계(DC·dewow·밴드패스)만 통과시킨 포락선을 L1 격자로 면적 평균한다. 상자는 꼭짓점(정답 ±1 P, ±3 트레이스 안 최대)을 씨앗으로 한 연결 성분의 외접 상자다.

$$
w_\ell = \frac{c_1 - c_0 + 1}{P_{L1}},\qquad h_\ell = \frac{r_1 - r_0 + 1}{P_{L1}},\qquad
\Delta_\text{AGC} = 20\log_{10}\frac{F_\text{post}/A_\text{post}}{F_\text{pre}/A_\text{pre}}
$$

$$
L = \frac{1}{N_c-1}\sum_{c}\mathbf{1}\!\left[\operatorname{corr}(q_{:,c},\,q_{:,c+1}) < 0.5\right]\quad(\text{위 25행})
$$

| 기호 | 뜻 | 단위 |
|---|---|---|
| $P_{L1}$ | L1 영상의 주기(= $P_\text{line}$ / 세로 샘플·px) | px |
| $\ell$ | 포락선 수준(꼭짓점 대비) | dB |
| $c_0, c_1, r_0, r_1$ | 상자 열·행 경계 | px |
| $w_\ell, h_\ell$ | 상자 폭·높이 | 주기 P |
| $A_\text{pre}, A_\text{post}$ | AGC 전(배경 제거 뒤)·후 꼭짓점 포락선 | 진폭 |
| $F_\text{pre}, F_\text{post}$ | 영점 + 2 P 아래, 관 응답(−40 dB 지지 + 5샘플 팽창) 밖 RMS | 진폭 |
| $\Delta_\text{AGC}$ | AGC가 꼭짓점 대비 바닥을 들어 올린 양 | dB |
| $q$ | 회색 내용 영상(0–255) | – |
| $L$ | 인접 열 상관이 0.5 미만인 쌍의 비율(세로 기둥 무늬 지표) | – |
| AIHub 범위 | tpipe 라벨 p5–p95: 폭 7.79–14.67 P, 높이 5.22–8.35 P (`inject.py` `AIHUB_WIDTH/HEIGHT_PERIODS`) | P |

## 3. 같은 모델을 실측 배경에 넣었을 때 (H1과 H2의 분리)

M3-2 단계 C 사전 점검(r0, fold 0, 주 칸, 4TU + IDS 배경, conf 0.25)의 `pipe_hyperbola` 적중 수 / 주입 수:

| 모델 | 0 dB | 6 dB | 12 dB | 18 dB | D0 Y0 (fold 0 / 5 fold) |
|---|---|---|---|---|---|
| M14 | 117/186 | 172/186 | **345/372 (93 %)** | 159/185 | 0/1 / **2/5** |
| M17 | 84/170 | 141/170 | **317/340 (93 %)** | 149/170 | 0/1 / 0/5 |
| M01 | 13/104 | 51/104 | **149/198 (75 %)** | 70/104 | 0/1 / **1/5** |
| M11 | 10/36 | 15/36 | 32/64 (50 %) | 18/36 | 0/1 / 0/5 |
| M10 | 8/50 | 19/50 | 44/98 (45 %) | 18/50 | 0/1 / 0/5 |
| M05·M06·M07·M08·M02·M19·M12 | | | 13–37 % | | 0/1 / 0/5 |
| M03·M04·M09·M15·M16·M18 | 0 | 0 | **0** | 0–1 | 0/1 / 0/5 |
| 전체(M01–M20 주입분) | 248/1058 | 463/1058 | 1053/1990 | 521/1057 | 0/20 / 3/100 |

(M13·M20은 이 사전 점검의 주입 목록에 없다. 원자료 `analysis/processing/m33_y0_vs_stagec_inject.json`.)

해석
1. **모델 고유 모양(H1)이 "검출 가능 여부"를 정한다.** 6모델은 실측 배경에서도 0 %다. 깊은 관(관 상단 6.7–16 P), 납작한 호, 짧은 측선(M09 εr 4, 측선 반폭 5.9 P)이 여기에 든다. 이 모델들의 Y0 0은 단독 측선 탓이 아니다.
2. **단독 측선(H2 + H3)이 나머지를 지운다.** 실측 배경에서 75–93 %인 M01·M14·M17이 단독으로는 5 fold에서 1·2·0이다. Y0 적중 모델은 주입 재현율 상위 모델의 부분집합이다(같은 순위).
3. 주입 쪽도 SNR 12 → 18 dB에서 재현율이 떨어진다(M01 75 → 67 %, M14 93 → 86 %, M17 93 → 88 %). 단계 C 판정서 §2의 AGC 포화 해석과 같은 방향이다. 단독 측선은 SNR이 무한대인 끝점이다. 배경이 없으면 AGC 창 RMS를 관 자신이 정하므로 날개가 꼭짓점과 같은 밝기가 된다(§2-1 전폭 20/20). 주입에서 쓴 개구 테이퍼도 없다. 그래서 단독 영상의 쌍곡선은 "가장자리에서 가장자리까지 고르게 밝은 아치 + 잔향 겹 호"가 된다. AIHub 라벨처럼 꼭짓점 주변만 도드라진 모양이 아니다.
4. 주입과 단독은 SNR·테이퍼·배경 질감·채움 모양이 함께 다르다. 그래서 이 대조만으로는 H2(질감)와 H3(AGC·채움) 몫을 따로 떼지 못한다. 분리는 §6 추론 실험이 필요하다.

| Y1 0.5 P | 50.5 | 1.07 | 81.5 | −12.5 | 0.543 | 0.029 | 33 | 0 |
| Y1 1 P | 53.5 | 1.00 | 55.5 | −11.8 | 0.339 | 0.033 | 23 | 1 |
| Y1 2 P | 59.5 | 0.89 | 36.7 | −13.7 | 0.327 | 0.044 | 14 | 4 |

- Y1 박스 75개의 구성: `manhole` 65(범주 d 52, a 4, 없음 9), `cavity` 1(d), `pipe_band` 3(b), `pipe_hyperbola` 6(b, 잘린 꼭짓점 덮개). 오검출은 대부분 내용 위쪽(y1 ≈ 0, 높이 11–34 px)에 있다.
- 경로 비교([`figures/m33_y0_diag/y1_paths_M04.png`](figures/m33_y0_diag/y1_paths_M04.png)). M04 0.5 P에서 "절단 → r0"(D0 경로)에만 세로 기둥 무늬가 있다. "절단 → AGC 없음"과 "전체 r0 → 절단"에는 없다. $L$ 중앙값은 D0 경로 0.029–0.044, 전체 r0 → 절단 0, Y0 0이다. AIHub tpipe 기준 crop은 중앙값 0, p90 0.012다.
- 측선 단위로 $L$과 박스 수의 순위 상관은 약하다(Spearman ρ = −0.13, p = 0.27, n = 80). $L$은 무늬의 유무만 잡고, 오검출을 부르는 "기둥 모양"까지는 잡지 못한다. 기제의 근거는 경로 비교 그림과 조건별 단조 경향(창/기록 ↑ → 박스 ↑)이다.
- 그림: [`figures/m33_y0_diag/y1_05p_tiles.png`](figures/m33_y0_diag/y1_05p_tiles.png), [`figures/m33_y0_diag/y1_2p_tiles.png`](figures/m33_y0_diag/y1_2p_tiles.png)(빨강 manhole, 노랑 cavity, 보라 pipe_band, 초록 pipe_hyperbola, 라벨 = fold·클래스·점수).
- 함의: D0 Y1은 "기록 끝 근처 관"을 흉내 내지 못했다. 실측 4TU 기록(512 × 0.098 ns ≈ 50 ns)에서 AGC 창/기록은 약 0.32다. Y1의 0.80–1.07은 실측에 없는 영역이다. D0 §5-1·§5-2의 Y1 수(PP-d 처리 28·17·6·2 등)는 거의 이 인공물 위의 오검출에서 나왔다.

## 5. 다음 검증에서 합성 자료를 다시 쓸 때의 권고

1. **단독 gprMax 측선을 r0 재현율 시험에 쓰지 않는다.** 관 응답(전체 − `_bg`)을 실측 배경에 주입하는 단계 C 방식을 기본으로 한다. 단독 측선을 꼭 써야 하면 시드 고정 잡음이나 실측 배경 질감을 먼저 더하고 SNR을 명시한다. AGC 없는 레시피(G4)나 상한 AGC(G2 β 0.5)는 별도 조건으로 함께 보고한다.
2. **모델 선택**: 실측 배경에서도 0 %인 M03·M04·M09·M15·M16·M18은 검출 기반 게이트(G3류)의 분모에서 빼거나 따로 보고한다. 정보가 있는 모델은 M01·M14·M17(12 dB 75–93 %)과 M10·M11(45–50 %)이다. 분포 안 판정은 −6 dB 폭보다 **단계 C 경험 재현율**로 미리 고정하는 편이 맞다(폭 기준 안 7모델 중 M09·M18은 주입에서도 0 %).
3. **기록 끝 근처 관(Y1류)**: 기록을 자른 뒤 다시 처리하지 않는다. 전체 기록을 r0로 처리한 뒤 진폭을 자르거나, AGC 창을 원 기록에서 고정해 넘긴다. 주기 고정(이미 함)만으로는 부족하다. 지금 방식이면 창/기록 ≥ 0.8에서 세로 기둥 오검출이 생긴다.
4. **측선 길이·채움**: 2.2 m 측선은 L1에서 13–29 P라 타일 하나에 오른쪽·아래 L자 채움이 생긴다. 이것은 학습에 없던 모양이다. 새 합성이 필요하면(electromagnetic-simulation-expert) 측선을 길게 하거나(≥ 256 px, 4TU dt 기준 약 5 m), 주입 방식으로 실측 측선 폭을 쓴다.
5. **점수 기록**: 합성 조건은 conf 0.001까지 꼭짓점 상자 최고 점수를 남긴다. 그래야 "0.25 아래로 약하게 봤다"와 "아예 못 봤다"를 가를 수 있다.
6. **영점 근처 관(PP-d 시험)**: 합성에 영점 바로 아래 관이 없다는 한계(판정서 §7-1 2)는 그대로다. 위 1–3을 지켜도 Y0는 PP-d 검정력을 주지 않는다.

## 6. 추론 실험 명세 (메인 세션 권고, 이번에는 실행하지 않음)

H2와 H3의 몫을 가르려면 GPU 추론이 필요하다. 구현은 python-expert, 결과 해석은 gpr-processing-expert가 맡는다.

| 실험 | 입력 변형 (Y0 20모델 × fold 0–4, N2-a′ `last.pt`) | 기록 | 가르는 것 |
|---|---|---|---|
| E0 | 원본 r0 | conf 0.001, 꼭짓점 포함 `pipe_hyperbola` 최고 점수 | 0.25 아래 약한 반응이 있는지 |
| E1 | 레시피 G4(`gain_mode="none"`), G2(`agc_capped`, β 0.5) | 같음 | AGC 날개 들림의 몫(H3-gain) |
| E2 | 관 단독 응답 + 시드 고정 백색잡음(밴드패스 뒤 SNR 6·12·18·30 dB, 시드 20261115) → r0 | 같음 | 잡음 바닥이 AGC 포화를 막는 몫(H2 일부) |
| E3 | 관 단독 응답을 4TU 배경 측선(단계 C 목록, 같은 SNR)에 주입, 개구 테이퍼 없음 | 같음 | 테이퍼 없는 전폭 날개의 몫(E2와 대비) |
| E4 | r0 내용을 가운데 두고 좌우 채움 분할(L자 채움 제거) | 같음 | 채움 모양의 몫(H3-pad) |

- 규모: 영상 20 × 변형 약 10 × fold 5 = 약 1,000타일. GPU 한 계열, 약 5분 이내(추정). 출력은 `runs/eval/m33_y0_diag_infer/` 제안.
- 판정용이 아니므로 사전 등록은 필요 없다. 그래도 시드와 변형 정의를 스크립트에 고정한다.

## 7. 가정·한계

- 관 단독 응답은 bg 가운데 트레이스를 빼서 얻었다(가로 균일 가정, 근거 bg 가로 변화 ≤ $1.8\times10^{-5}$). median 배경 제거는 비선형이라, 상자는 선형 단계만 거친 포락선으로 쟀다.
- AIHub 범위는 라벨 상자(사람이 그림)이고 합성 상자는 포락선 수준 상자다. 정의가 달라 크기 비교는 경향으로만 쓴다.
- 단계 C 대조는 fold 0, r0, 사전 점검 칸만이다. 주입은 개구 테이퍼·유한 SNR·실측 측선 폭을 쓰므로 단독 Y0와 여러 조건이 함께 다르다(§3 4).
- 깊이 값(m)은 이 문서에서 쓰지 않는다(검출 진단 전용).
