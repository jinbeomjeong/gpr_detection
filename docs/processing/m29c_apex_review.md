1. 표본 169개(수동 39 + 자동 130)를 눈가림으로 분류했다. **진짜 꼭짓점(T)은 41개**다. 수동 후보는 27/39, 자동 후보는 **14/130(10.8 %; 현장 후보 수로 가중하면 약 8 %)**이다. 자동 후보에서 가장 많은 거짓 유형은 층 반사(L) 48/130이다. 그다음이 짧은 호·클러터(C) 19, 날개 교차(X) 15, 꼭짓점 어긋남(W) 10, 자료 이음(A) 9, 기록 끝(N) 7이다. `spec_eval_4tu_v1.md` §3-4의 "정밀도 대략 절반"(가정)보다 훨씬 낮다.
2. 결정된 규칙(곡률 v가 메타 v ±30 % 밖이면 제외, 구할 수 없으면 유지 + 플래그)을 적용한 결과다.
   - 전체: T 36/41(87.8 %)을 남기고 거짓 32/128(25.0 %)을 거른다.
   - 자동 후보: T 11/14를 남기고 거짓 31/116(26.7 %)을 거른다. 남은 자동 후보 중 T 비율은 10.8 %에서 **11.5 %**로 거의 그대로다.
3. 잘 못 가르는 이유는 둘이다.
   - (a) 거짓 후보의 60 %(77/128)는 곡률 v를 구할 수 없다(`insufficient_picks` 등). 규칙상 이들이 남으므로 거르는 비율이 처음부터 제한된다.

4. 권고: **±30 %는 바꾸지 않는다**(사용자 결정 3). 다만 지금 형태로는 주 결과 필터 효과가 거의 없다. 대안 B–E(§6)를 근거와 함께 제시하니 사용자가 고른다.
5. 재판독(2026-11-07, §9): 30개를 눈가림으로 다시 분류했다. 9유형 일치 23/30(κ 0.72), **T 대 거짓 29/30(κ 0.91)**. 바뀐 T는 수동 후보 G143 하나다(T → W). 자동 후보 정밀도 10.8 %와 A·B·B+D의 자동 후보 수치는 바뀌지 않는다. 첫 분류는 T 대 거짓 판정에 그대로 쓰고, 거짓 하위 유형 정의만 다듬는다(§3 정의 다듬기, G143은 "T(경계, 재판독 W)" 주석).

## 4. 곡률 v 검사 (분류 확정 뒤)

### 4-1. 식과 판정

후보마다 깊이 경로와 같은 박스(`eval_depth_4tu.candidate_box`)와 픽(`extract_picks`, 후보 = `apex_hint`)을 쓴다. 직선 광선 점 산란 피팅으로 $v_\text{curv}$를 구한다.

$$\tau(x)=\frac{2}{v}\sqrt{\left(\frac{v\,t_0}{2}\right)^2+(x-x_0)^2},\qquad r=\frac{v_\text{curv}}{v_m},\qquad \text{in}\iff |r-1|\le 0.30$$

- 피팅은 `fit_curvature(picks, radius_m=0, air_gap="ground")`이다. 깊이 경로는 공기결합 자료에서 이 피팅을 거부하므로, **QC 전용으로 ground 라벨을 일부러 넘겼다.** 결과는 깊이에 쓰지 않는다.

| 기호 | 뜻 | 단위 |
|---|---|---|
| $\tau$ | 검출 영점 뒤 픽 시각 | ns |
| $x, x_0$ | 트레이스 위치, 꼭짓점 위치 | m |
| $t_0$ | 꼭짓점 시각(영점 기준) | ns |
| $v_\text{curv}$ | 곡률 피팅 속도 | m/ns |
| $v_m$ | 메타 속도 $c/\sqrt{\varepsilon_{r,\text{used}}}$ | m/ns |
| $r$ | 속도비 | – |

`curvature_v_unknown` 사유는 실행 전에 정했다.

| 사유 | 조건 |
|---|---|
| `no_apex` | 꼭짓점 후보 없음(힌트 창 불일치 등) |
| `insufficient_picks` | 픽 9개 미만이거나 한쪽 3개 미만(spec_depth §5-4) |
| `fit_failed` | 수렴 실패 또는 경계에 걸림 |
| `unstable` | $\sigma_v/v_m>0.15$(2σ 구간이 ±30 % 띠 전체보다 넓음) 또는 inlier 비율 < 0.5 |

## 5. 공기층 굴절 등 물리 편향이 ±30 % 판정에 주는 영향

정확한 공기층 광선 시각(`refraction.reflection_times`, 영점 = 지표 반사 $2h/c$)에 같은 직선 광선 R = 0 피팅을 했다. 표는 `m29c_refraction_bias.csv`(εr 9·16, h 0–0.3 m, $d$ 0.2–1.5 m, 반개구 0.3/0.5/0.8 m, R 0/0.1 m)에서 εr 9, 반개구 0.3 m(4TU T 픽 반개구 중앙값 0.34 m)를 뽑은 것이다.

|---|---|---|---|---|---|---|---|
| 0 | 0 | 1.000 | 1.000 | 1.000 | 1.000 | 1.000 | 1.000 |
| 0 | 0.1 | 1.181 | 1.136 | 1.090 | 1.063 | 1.048 | 1.032 |

(εr 16, h 0.05, R 0: 1.825 / 1.567 / 1.315 / 1.181 / 1.120 / 1.072. 개구가 넓을수록 커진다: h 0.05, d 0.5에서 반개구 0.8 m는 1.497.)

1. **편향은 한쪽(r > 1)이고 얕을수록 크다.** 원인은 세 가지다.
   - 공기층 굴절: 날개가 납작해진다.
   - R = 0 점 산란 피팅: 관경이 있으면 날개가 관 중심 쪽에서 나온다(+3–18 %).
   - 사교 교차: 1/sinθ, 60°면 +15.5 %(`band-depth` 메모 근거, `spec_depth`에는 미기재).
   - 그 밖에 메타 εr 불확도 ±15 %는 r에 ±7.5 %로 들어가는 활동 공통 오차이고, 엔벨로프 픽은 날개에서 약간 이르게 잡힌다(gprMax M20: −0.09 ns, r을 조금 키움).
   - r < 0.7을 만드는 물리 메커니즘은 진짜 직각 관에는 없다. 낮은 r은 한쪽 날개(W)·V 교차(X)·클러터(C)의 특징이다.
2. **관측된 T는 이 모형의 큰 h와 맞지 않는다.** 판정이 난(known) T 26개의 r은 중앙값 1.07, 사분위 약 0.99–1.25다(`unstable`·`fit_failed` 피팅값 4개를 넣은 30개 기준은 0.995–1.33). 후보 깊이 0.5–0.72 m인 T 11개의 중앙값은 약 1.06이다.
   - 광선 모형으로 h ≥ 0.05 m면 이 깊이에서 1.12–1.26이 나와야 한다. 관측은 **실효 공기층 h ≲ 0.02 m**(또는 h ≪ λ_air ≈ 0.6 m에서 광선 모형이 맞지 않음)와 R 편향만으로 설명된다. 이는 M2-7(`fourtu_explore.md`)의 "공기층 ≈ 0" 결론과 같다.
   - 광선 모형은 h → 0+에서 h = 0(직선 토양 경로)과 이어지지 않는다(h 0.02에서 이미 d 0.2 m의 r이 1.48). 근거리장 영역(h ≪ λ)에서는 광선 표를 상한 추정으로만 본다(**가정**).
3. **±30 % 판정에 주는 편향**: 띠가 1을 중심으로 대칭이라, 진짜 꼭짓점이 실제로 있을 곳(1.0–1.2 이상, 얕으면 더 큼)과 어긋난다.
   - 실측: 제외된 T 5개는 모두 r > 1.3(1.35–1.98)이고 $d_c$ 0.15–0.57 m다. unknown 처리된 T 2개(G066 1.50, G164 2.06)도 얕다. 아래쪽(r < 0.7)으로 잘린 T는 없다(G157 0.71이 경계 안).
   - 얕은 구간에서 T를 남기는 비율이 7/10으로 가장 낮다. 이 손실은 4TU 깊이 집합을 얕은 쪽에서 더 잃게 만든다(M2-8의 얕은 치우침과 방향이 같지는 않지만 구간별 재현율이 달라진다).
   - 반대로 위 끝 1.3은 L을 거르는 핵심 경계다. L의 r 중앙값은 1.65다. 위 끝을 올리면 L을 덜 거른다.

### 9-5. 판단과 권고

1. **T 대 거짓 판정은 첫 분류를 그대로 쓴다.** κ 0.91이고, 확신도 높음은 10/10이며, 자동 후보 T 판정 변동은 0/24다. B+D 채택(2026-11-07 사용자 결정)의 근거 수치는 판독 변동 안에서 바뀌지 않는다. 잠근 첫 판독 시트는 고치지 않는다. G143은 "T(경계, 재판독 W)"로 주석만 단다. 민감도로 G143 = W일 때의 수치(§9-4 표의 치환 열)를 함께 적는다.
2. **거짓 하위 유형의 개수는 정밀한 값으로 쓰지 않는다.** 확신도 중간·낮음의 일치는 13/20이고, 불일치는 모두 겹치거나 경계가 흐린 정의에서 나왔다. 명세 개정 때(별도 작업) 다음과 같이 정의를 다듬기를 권한다. 다듬은 정의는 T 판정을 바꾸지 않으므로 A·B·E 수치에는 영향이 없다.
   - (a) **T/W 빈칸 없애기**: T는 $|x_c-x_\text{apex}|\le 0.10$ m 이고 $|t_c-t_\text{apex}|\le 1/f_c$(500 MHz에서 2 ns)인 경우로 둔다. 나머지 쌍곡선 위 후보는 모두 W로 둔다. 지금은 0.10–0.15 m에 정의가 없다.
   - (b) **우선순위**: N > A > 사건 유형(T, W, X, B, L, C) > U. 메커니즘 유형(N·A)이 먼저다. 창이 잘렸어도 기준 사건(호·층)이 보이면 U로 두지 않는다(R03 유형).
   - (c) **L/C/X 기준**: L은 후보 시각 ±½ 주기에서 보이는 창 폭의 2/3 이상 이어지는 층이다. X는 후보 ±0.1 m·±1 ns 안에서 두 경사 사건이 만나는 경우다. 둘 다 아니면 C다.
   - (d) **B/A**: 띠 끝이 트레이스 이음과 겹치면 A다.
3. 첫 판독 확신도 낮음 67개를 다듬은 정의로 다시 분류하는 일은 B+D 결정에 필요 없다. D를 구현한 뒤 D 플래그와 라벨 A·N을 맞춰 볼 때 필요하면 한다(선택).
4. 한계: 재판독자는 첫 판독과 같은 에이전트(같은 모델, 판독 기억 없음)다. 따라서 이 값은 같은 판독 도구의 재시험 일치도다. 다른 판독자(사람)의 일치도는 아직 없다. 표본 30개는 작아서 확신도별 일치의 구간이 넓다.
