### 1-3. F5-B 정의 (권고안)

- 참 꼭짓점: $(j_a, t_{a0})$. $j_a$ = json `apex_trace_index`, $t_{a0}$ = v1.4 P2 정의(잡음 없는 처리의 꼭짓점 포락선 최대 시각).
- **최근접 kept** $\kappa_X$: 규칙 X의 kept 가운데 꼭짓점 창(v1.4: $|j-j_a|\le3$, $|t-t_{a0}|\le0.5/f_c$, 닫힌 구간) 안에 있는 것 중에서 고른다. 기준은 $|t-t_{a0}|$가 가장 작은 것이다. 같으면 $|j-j_a|$가 작은 것, 그것도 같으면 트레이스 색인이 작은 것이다. 결정적이고 순위와 무관하다.
- 오차: $\varepsilon_t(X)=|t(\kappa_X)-t_{a0}|$(ns), $\varepsilon_j(X)=|j(\kappa_X)-j_a|$(트레이스).
- 쌍: (모델, $\rho$, $\Delta$, 시드)마다 X와 current 모두 꼭짓점 창 안 kept가 있는 경우다.
- 쌍마다 판정:
  - **X 악화**: $\varepsilon_t(X)>\varepsilon_t(\text{cur})+0.5\Delta t$ 또는 $\varepsilon_j(X)>\varepsilon_j(\text{cur})+1$
  - **X 개선**: 같은 문턱으로 반대 방향
- **F5-B 통과** ⇔ 다음 셋을 모두 만족한다. 모든 관 모델의 쌍을 모은 수다.
  1. 악화 쌍 수 ≤ 개선 쌍 수(부호 비교; 대칭 잡음 흔들림은 상쇄된다)
  2. $\text{median}\,\varepsilon_t(X)\le\text{median}\,\varepsilon_t(\text{cur})+0.5\Delta t$
  3. 쌍이 20개 이상이다. 미만이면 F5-B는 **판정 불가**이고 순위 5로 센다(보수적).
- 대칭성 점검(공개 위험 대응): 같은 정의를 X와 current를 바꿔 적용한 결과(current의 비열등)도 보고한다. 두 방향이 모두 통과하면 "위치 차이 없음"이다. X만 통과하면 "X 개선"이다.
- 0.5 Δt·1 트레이스는 v1.4 F5 상수 그대로다. 이 문턱은 묶음 1 결과로 고르지 않았다.
- 하네스 출력 추가(결과 전 구현): `kept_nearest_trace`, `kept_nearest_sample`(위 정의), `n_kept_in_window`. 기존 `kept_apex_trace/sample`(순위 최상위)은 보고로 남긴다.

### 2-1. V9 — 영역 G에 "늦은 뮤트에서 바닥 이탈" 조건 추가 (W9 승인 2026-11-11, v2 결과 전; 본문 §2·§8-2에 반영됨)

**문제(결과 전, EM v2 점검 사실에서; 모델 선택 근거일 뿐 판정 결과 아님)**:
- v2 점검 $\Lambda_\text{est}$(Δ −1 / 0 / +1 / +2.35):

  | 쌍 | 모델 | $\Lambda_\text{est}$ |
  |---|---|---|
  | P0 | S6P_D14_S040_J2 | 18.7 / 21.2 / 11.4 / **4.5** |
  | P1 | S6P_D16_S040_J3 | 59.0 / 68.0 / 35.8 / **14.1** |
  | P2 | S6P_D15_S045_J4 | 77.2 / 87.5 / 47.8 / **18.5** |

- §2-2(v1.4)의 기작은 다음 두 가지를 예측한다. 바닥이 걸린 꼭짓점은 $A_0<0.1L$, 곧 $\Lambda>10$일 때 사라진다. 늦은 뮤트 $\Delta_l$에서 다시 잡히려면 $\Lambda(\Delta_l)\le10$이어야 한다.
- P1·P2는 $\Lambda(+2.35)>10$이다. 그래서 기작대로라면 늦은 뮤트에서도 꼭짓점이 바닥에 남고 $e\approx0$이다.
- 지금 정의에서는 영역 G가 $\Delta_e$만 본다. 그러면 P1·P2의 짝이 $Q\wedge G\wedge C$이면서 $e\le0.1$이 된다. 다른 짝도 모두 그러면 **순위 7(기작 반증)**이다. 하지만 이것은 기작이 예측한 결과이지 반증이 아니다(잘못된 반증).
- 같은 이유로 P1·P2의 부분 회복($0.1<e<0.5$)은 순위 6(약한 재현)으로 간다. 이것도 잘못된 보류다. 결함이 약한 것이 아니라 늦은 뮤트가 바닥을 벗어나지 못한 것이다.
- 해당 경우: P0가 Q·C를 잃거나(잡음·대조 문제), P0도 효과가 없을 때 P1·P2가 판정을 정한다.
- P0만 $\Lambda(+2.35)=4.5\le10$으로 기작을 시험할 수 있는 짝이다. 묶음 1 S6P_D15_S040도 7.95로 이 조건을 만족했다. 그래서 묶음 1 판정은 V9로 바뀌지 않는다(참고, v2와 별개).
