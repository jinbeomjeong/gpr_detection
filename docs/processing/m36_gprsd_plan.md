## 0. 요약

1. **"주기 51 샘플 ↔ 200–400 MHz 불일치"는 대부분 측정 정의 문제로 보인다(파일럿, 판정 아님).**
   - 표식창 51개에서 모든 도로가 **14.4–14.8 샘플**에 둘째 스펙트럼 봉우리를 가진다. 상대 진폭 p50은 0.60이다.
   - 이 값은 dt 가설 A에서 227 MHz, 가설 B에서 268 MHz로, 문서의 200–400 MHz 안에 든다.
   - 51 샘플은 낮은 주파수 성분이다. r0 주기 추정기는 탐색 상한이 $n_s/4$ = 80 샘플이라 이 성분을 고른다.
   - M3-6에서는 반송파 주기를 꼭짓점 파형으로 다시 정의해 확정한다.
2. **검출 영상(L1) 축척은 dt와 무관하다.**
   - $s_y=P/P^*$, $s_x=s_y\,\delta_z/\Delta x$이고, $P$(샘플)와 $\delta_z$(m/샘플, 곡률에서 나옴)만 쓴다.
   - dt 가설 A/B는 $\varepsilon_r$ 해석만 바꾼다. 곡률 깊이가 dt에 불변이라는 [S] U5와 같은 논리다.
   - 따라서 **M3-6a(검출 축척: $P$·$\delta_z$)만 M3-4·M3-3b의 선행 조건**이다.
   - **M3-6b(영점·$\varepsilon_r$, 깊이용)**는 미결로 닫을 수 있다.
3. **영점은 미결 폭이 크다.**
   - 기록 시작(샘플 0)에 조용한 선행 구간이 없다. 샘플 0의 RMS가 기록 중간과 비슷하다.
   - CementRoad2 3측선에는 주기 약 17 샘플의 잔여 평균 파형이 샘플 16–18에 봉우리를 남긴다.
   - 앞 59 샘플 절단(가설 B-front)이면 영점이 음수 샘플일 수도 있다.
   - 후보 범위는 대략 −40…+20 샘플이다. $\delta_z$ 0.012 m에서 깊이로 약 −0.48…+0.24 m다.
   - 영점과 $\delta_z$는 쌍곡선 피팅에서 엮여 있다(§3). 영점의 물리 판정은 electromagnetic-simulation-expert에 맡긴다.
4. **M3-4는 L0 좌표로 저장하고, r0와 분리된 전용 라벨 보기 영상에서 그리기를 권고한다.**
   - 라벨 단위는 측선마다 표식 ±300 트레이스 창이다. 겹치는 AsphaltRoad1 1000/1050 창은 합쳐 측선당 16창, 모두 48창이다.
   - 창 안의 관로 쌍곡선은 전수로 그린다. 박스와 꼭짓점 점을 함께 기록한다.
   - 사용자 작업 시간은 약 1.5–3 h다.

## 3. 물리 관계 (dt가 빠지는 정리)

$$P_\text{ns}=P\,\Delta t,\qquad f=\frac{1}{P\,\Delta t},\qquad \delta_z=\frac{v\,\Delta t}{2},\qquad \lambda_m=\frac{v}{f}=2\,\delta_z\,P,\qquad \varepsilon_r=\Big(\frac{c\,\Delta t}{2\,\delta_z}\Big)^2$$

샘플·트레이스 단위의 쌍곡선(지면결합, 점산란 R = 0):

$$(\tau-\tau_z)^2=(\tau_a-\tau_z)^2+\Big(\frac{(u-u_0)\,\Delta x}{\delta_z}\Big)^2$$

반경 R 관이면 점근선 교차 시각은 $\tau_z-R/\delta_z$ 샘플이다.

L1 축척([DI] §4-4):

$$s_y=\frac{P}{P^*},\qquad s_x=s_y\,\frac{\delta_z}{\Delta x}$$

| 기호 | 뜻 | 단위 |
|---|---|---|
| $P$ | 반송파 주기 | 샘플 |
| $\Delta t$ | 샘플 간격 (가설 A 0.3022 / B 0.2553) | ns |
| $f$ | 반송파 주파수 | GHz |
| $v$ | 매질 속도 | m/ns |
| $c$ | 0.299792458 | m/ns |
| $\delta_z$ | 샘플당 깊이 $v\Delta t/2$ | m/샘플 |
| $\lambda_m$ | 매질 안 파장 | m |
| $\varepsilon_r$ | 비유전율 | – |
| $\tau,\ \tau_a,\ \tau_z$ | 시각, 꼭짓점 시각, 영점 | 샘플 |
| $u,\ u_0$ | 트레이스 번호, 꼭짓점 트레이스 | 트레이스 |
| $\Delta x$ | 트레이스 간격 (0.03, 미검증) | m |
| $R$ | 관 반경 | m |
| $P^*$ | L1 목표 주기 (6.0) | px |
| $s_y,\ s_x$ | L1 1 px당 샘플·트레이스 | 샘플/px, 트레이스/px |

함의는 다음과 같다.

1. $\delta_z$는 곡률에서 샘플·트레이스 단위로만 나온다. **dt와 무관하고 $\Delta x$에 비례한다.**
2. **L1 영상은 $P$와 $\delta_z$만으로 정해진다(dt 무관).** dt A/B는 $f$와 $\varepsilon_r$만 바꾼다.
   - $P$ 14.6이면 A 227 MHz, B 268 MHz로 둘 다 문서 범위 안이다. 그래서 문서 주파수로는 A와 B를 가를 수 없다.
   - $P$ 51.2이면 A 64.6 MHz, B 76.5 MHz로 문서 범위 밖이다.
3. $\varepsilon_r$($\delta_z$ 0.012 가정): A 14.3($v$ 0.079 m/ns), B 10.2($v$ 0.094 m/ns). 둘 다 습한 노상에서 가능한 값이라 데이터만으로는 가를 수 없다.
4. 매질 파장: $P$ 14.6이면 $\lambda_m$ = 0.35 m(200–400 MHz, $v$ 0.08–0.10 m/ns와 맞음), $P$ 51.2이면 1.23 m.
5. **$\tau_z$와 $\delta_z$는 함께 움직인다.** 영점을 0으로 고정한 채 맞추면, 영점이 실제로 어긋난 만큼 곡률 해석이 비뚤어진다. 그래서 $\tau_z$를 공통 미지수로 두고 작은 점 산란체(R ≈ 0)에서 함께 맞춘다(D2).
   - 관 반경 혼동: R 0.05 m면 −4.2 샘플, 0.15 m면 −12.5 샘플($\delta_z$ 0.012).
   - 반경을 미지수로 함께 추정하지 않는다(Giannakis 2022, 이 프로젝트 규약).
6. L1 영향: $P^*$ 6, $P$ 14.6, $\delta_z$ 0.012이면 $s_y$ 2.43, $s_x$ 0.97, 내용 높이 132 px다(현재 38 px). 쌍곡선 폭은 3.5–9.1 P가 된다(현재 1–2.6 P, AIHub tpipe p50 11.4 P).

| D2s | 민감도 | $\tau_z$ ∈ {0, D3b 후보, D2 공통 추정}에서의 $\delta_z$. R ∈ {0, 0.05, 0.15 m} 고정에서의 $\tau_z$ | – | 같은 json |
| D3a | 기록 시작 상태 | 샘플 0–40의 RMS·평균 트레이스 포락선 측선별 표(파일럿 확장) | 12측선 | `m36_gprsd_zero.json` |
| D3b | CR2 잔여 파형 | 포락선 피크 샘플, 측선 방향 안정성(500 트레이스 블록마다 피크 샘플의 산포). 안테나에 고정된 직접파라면 거의 일정하고, 슬래브 바닥이라면 줄눈·두께에 따라 변한다 | CR2 3측선 | 같은 json |

| D5 | L1 결과 | 새 $P$·$\delta_z$로 내용 높이, 쌍곡선 폭(P 단위), AIHub 범위(8–15 P)와 비교. r0 값과 나란히 | 계산만 | `m36_gprsd_l1.json` |
| D6 | 외부 근거 | 논문 [1] Zhou 2018·[2] Wang 2023, GPR-SD 저장소, MATGPR 설명서: 장비·중심주파수·샘플 수·시간창·처리 순서·영점 조정·재표본 여부 | – | web-research-expert(절약), `docs/research/`에 둔다 |

- 스크립트는 모두 `analysis/processing/m36_gprsd_*.py`(이 에이전트 쓰기 범위)에 둔다. 그림은 `docs/processing/m36_*.png`(그림 작성 시 dataviz 스킬)에 둔다.

## 5. M3-4 계획 (GPR-SD 관로 라벨)

### 5-1. 라벨 단위

- 관로 표식 17건 × 측선 3개.
- 창 = [표식 − 300, 표식 + 300] 트레이스를 측선 범위로 자르고, 같은 측선에서 겹치는 창은 합친다.
  - AR1 1000·1050 → [700, 1350].
  - 측선당 16창, **모두 48창**이다(curator가 `windows.csv`로 확정).
- ±300을 쓰는 이유
  - 표식 오차 ±50–100에 쌍곡선 반폭(파일럿에서 눈으로 본 약 30–60 트레이스)과 문맥을 더한 값이다.
  - 제공처 표식창(±150)은 표식 오차가 크면 쌍곡선이 잘린다.
- 측선 3개의 트레이스 수가 최대 108 다르므로, 같은 표식 번호를 측선마다 그대로 쓴다(근사, [C]).

### 5-2. 라벨 보기 영상 (Q6, 검출 입력 아님)

- 저장 진폭을 측선 전체 |amp| p99로 대칭 클립([R] 권고)하고 8비트 회색으로 만든다.
- 정수 배율: 기본 가로 2 px/트레이스, 세로 2 px/샘플이다. 창 601–651 트레이스 × 321 샘플 → 약 1,202–1,302 × 642 px.
- 축·표식선은 넣지 않는다. 창 중심이 표식이라는 사실만 작업 화면 문구로 알린다. 표식선이 있으면 그 근처만 그리게 될 수 있어서다.
- 렌더링 설정(배율·클립 값·창 원점)은 `render_config.json`에 남기고 sha256을 기록한다. 영상 → L0 변환은 이 설정의 정확한 아핀 변환이다.
- **r0·L1과 무관**하므로 M3-6a 결과나 Q2 결정이 바뀌어도 라벨이 흔들리지 않는다.
- 이 방식은 [MJ] §8-1의 두 조건 중 "L0 좌표로 저장"을 택한 것이다.

- 라벨 지침(curator 작성, 박스 규약은 cv-detection-expert 승인)

  5. 측선과 평행한 관(수평 띠)은 `pipe_band`로 한다(드물 것으로 예상).

## 6. M3-3b로 넘길 것 (범위만, 설계는 cv-detection-expert)

1. 입력
   - 동결 라벨(sha), `windows.csv`
   - Q2에 따른 GPR-SD 렌더링: (a) 자료셋 고정 $P$·$\delta_z$ / (b) r0 측정 51 / (c) 둘 다
   - 가중치 N2-a′ 5 fold, PP S3(운용 기본값), r0
2. 지표 후보([MJ] §8-1)
   - `pipe_hyperbola` 박스 AP50·재현율
   - 박스 규약에 덜 민감한 보조 지표: 꼭짓점이 박스 안에 드는 비율
   - 창 안 FP 수
   - PP 전·후
   - 평행 3측선 일관성(표식마다 k/3 측선 검출)
3. 평가 영역
   - 라벨 창 안만 센다. `ignore` 영역은 뺀다.
   - 측선 전체를 추론한 뒤 박스 중심이 창 안인 것만 센다.
   - 창 밖 FP는 표식이 불완전하므로 세지 않는다(보고하더라도 해석 제한을 단다).
4. 독립 단위
   - 도로 4곳. 도로가 같은 길의 차로라면 더 적다(§2-3, curator 확인 선행).
   - CI가 넓으므로 판정 여부는 사용자가 정하고, 통계 설계는 stats-design-expert가 맡는다.
5. 공개
   - Q2 (a)는 동결 경로를 바꾸는 것이다. 검출 결과를 보기 전에 물리 측정으로 정했다는 점, 그리고 r0 대비 차이를 사전 등록 문서에 적는다.
6. 범위 밖: GPR-SD 깊이(M3-6b 영점 미결). 필요하면 별도 항목으로 둔다.
