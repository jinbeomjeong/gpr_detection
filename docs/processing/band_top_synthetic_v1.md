1. **관 상단 = 관에서 온 첫 포락선 피크다. 관 신호는 이 시각보다 먼저 오지 않는다.** 관 단독 차분 응답(관 있음 − 관 없음)의 첫 포락선 피크는 기하 왕복시간 + 일정한 지연(PEC 2.87 ns, 공기 찬 PVC 3.06 ns, 2.5 mm 격자)에 놓인다. 층이 관 아래 1 $P$ 이상 떨어져 있으면 어떤 칸에서도 이 지연은 ±0.03 ns 안에서 같았다(표 2). 따라서 띠 묶음 안에서 **관 상단보다 이른 겹은 관이 아니다.** 지층, 또는 같은 파형의 앞 엽이 섞인 간섭이다.
2. **현행 픽(위 여유 1 $P$ + 첫 피크 ≥ 0.3 $E_\text{box}$)이 잡는 것은 "박스 위 끝에서 1 $P$ 위까지 안의 첫 사건"이다.** 박스를 $[t_\text{top}-0.4P+\delta,\ t_\text{top}+0.8P]$로 두면 관 위 $\Delta_L$에 있는 층은 대략 $\Delta_L \le 1.4P-\delta$일 때(층 진폭 ≥ 0.3 $E_\text{box}$) 픽을 가져간다. 깨끗한 A-scan 모의에서 이 규칙은 칸마다 예외 없이 맞았다(그림 `band_top_synthetic_preview.png`).
   - 위에 층이 없으면 $\delta\in[-1.5,+1.0]P$ 전 범위에서 정답이다(아래 층은 첫 피크 규칙이 막는다).
   - 위에 층이 1 $P$ 있으면 $\delta=0$에서도 층을 잡는다(PEC 3/3, PVC 2/3 칸).
3. **S3(조각별 창)에 대한 물리 판단: 채택 쪽.** 합집합 창은 낮은 조각의 트레이스에 창을 위로 넓히는 일만 한다. 위로 넓힌 구간에는 관 신호가 있을 수 없고 층·잡음만 들어올 수 있다. 박스를 낮게 그린 조각($\delta=+1P$)도 위 여유 1 $P$로 관 상단을 다시 잡는다(모든 칸 정답, 표 4). 따라서 물리적으로는 (C) 조각별 창이 (B) 합집합 창보다 나쁠 수 없고, 관 위 2.4 $P$ 안에 층이 있으면 낫다. 정량 판정(§7-5 +10 %p 기준)은 잡음·밴드패스·배경 경로를 넣은 gpr-processing-expert 실행으로 확정한다. → **확정: 불채택**(C가 나빠진 칸 0, 평균 이득 0.0 ~ +6.4 %p < +10 %p, `band_box_convention_depth.md` §8-4, D5).
4. **띠 상단 정의 권고**: "띠 상단 = 박스 위 끝에서 위로 1 $P$, 아래로 박스 끝까지 안에서 **관에 속하는** 첫 포락선 피크". 관에 속하는지 가르는 실용 기준은 **가로 범위**다. 층은 띠 박스 밖까지 이어지므로 masked median이 지운다. masked median을 쓴 모의는 360/360 칸×$\delta$(60칸 × 6)에서 모두 정답이었다(v1.1 정정: 처음에 120/120으로 잘못 적었다). 문제는 배경 제거를 못 하는 경우(`bg_none`, AIHub 띠의 41 %(gt_v1 339/817, `band_box_convention_depth.md` §8-6))와 박스 안에서만 보이는 국소 층이다.
5. **2D 대리의 타당성: 이 구성에서는 성립한다.** 같은 층(관 위 1 $P$, εr 12.7)의 3D 평행 관(점 쌍극자)과 2D TMz를 비교했다.
   - 관 단독 첫 피크 지연: 2D 2.928 ns, 3D x-편파 2.924 ns, 3D y-편파 3.019 ns. 차이는 ≤ 0.09 ns(0.05 $P$)다.
   - 층/관 진폭비: 0.32 / 0.33 / 0.37이다.
   - 픽 분류는 $\delta$ 6개 모두 같았다.
   - 다만 직접파 영점은 편파에 따라 3.38–3.81 ns로 달라서 깊이 영점 편향이 −1.8 ~ −4.3 cm로 갈린다. 이는 [S] 영점 규칙 문제이고 띠 상단 정의와는 무관하다.

### 사용자 확인 필요 사항

1. **층/관 진폭비 3은 현실적인 단일 경계로 만들 수 없었다.** 2D에서 PEC OD 0.1 m를 기준으로 하면 진폭비 3에는 $|r|\approx0.92$가 필요하다. 그래서 εr 40(포화 점토 수준)에서 잘랐고, 실제 진폭비는 PEC 위 1.85–2.01, 아래 0.90–1.10, PVC 1.21–2.51이다. 더 센 층(예: 물 포화 쇄석 위 아스팔트 하부)이 AIHub에 흔하다고 보면 진폭비를 키운 추가 세트를 요청할지 정해 주세요. 결론 2·3의 방향은 진폭비 ≥ 0.3이면 바뀌지 않는다.
2. **(v1.1 §8에서 해소)** **파형 울림(ringing)을 넣지 않았다.** AIHub 띠 박스 높이는 반송파 4–5 주기인데, 이 실험의 Ricker 반사는 약 2 주기다. 실제 안테나 울림이 겹을 더 만들면 "앞 엽"과 "층"을 구분하기 더 어렵다. 장비(NM 32채널) 파형을 모르므로, 감쇠 진동 파형(`#excitation_file`) 변형 세트를 추가할지 정해 주세요. 2D라서 30개 칸에 약 2분이면 된다.
3. 지면결합 h 0 위주이고, 공기결합 h 0.1은 2개만 넣었다(결과 방향은 같다, 표 3).

## 1. 모델 설계

### 1-1. 기하와 2D/3D 선택

- 측선이 관 축과 평행하고($\theta=0$) 관 바로 위를 지나면($y=0$), 모든 트레이스가 같은 응답을 낸다([B] §1-1). 띠 = 한 A-scan의 반복이다.
- 2D TMz 모델의 평면 밖 축(z)을 **관 축 = 측선 방향**으로 읽으면, 관 바로 위 A-scan 하나가 평행 관 띠의 트레이스 하나와 기하가 같다. 수평 층도 z로 불변이므로 기하가 맞다. 남는 차이는 선원(2D 선 전류 대 3D 점 쌍극자)의 파형·퍼짐이다. 이것은 3D 확인 모델 6개로 쟀다(결론 5, 표 3).
- 그래서 주 자료는 2D 층상 매질 + 관의 **꼭짓점 A-scan 1개**(+ 관 없는 짝, + 균질 배경)다. 의사 띠(트레이스 40–160 반복, 잡음, 박스)는 gpr-processing-expert가 [B] §9-2 방식으로 만든다.
- 측방 이격($y\ne0$)·사교·경사·관 굽힘처럼 트레이스마다 정답이 달라지는 경우는 이번 범위가 아니다. [B] §9-3 P04–P07로 남긴다.

### 표 1. 관 상단 정답 $t_\text{top}$의 위상 기준

$t_\text{top}$ = 관 단독 차분 응답의 첫 포락선 피크(≥ 0.3 최대, 포물선 보간)다. $\tau_v$ = 표면에서 관 상단까지의 수직 기하 왕복시간(층 포함)이다.

| 구간 | $t_\text{top}-\tau_v$ (ns) | 해석 |
|---|---|---|
| PEC, 층이 관 아래 ≥ 1 $P$ (12칸) | 2.843–2.870 | 균질 기준 지연 2.87 ns(파형 지연 $\sqrt2/f$ = 2.83 + 엽 이동). 층 영향 ≤ 0.03 ns |
| PEC, 층이 관 위 (15칸) | 2.865–2.920 | 관 위 층은 관 단독 응답의 위상을 거의 바꾸지 않는다 |

### 표 2. 직접파 영점으로 낸 깊이 오차 (참고, [S] 영점 경로 아님)

$d=v_\text{eff}(t_\text{top}-t_\text{direct})/2$를 썼다. $v_\text{eff}$는 표면–관 상단 시간 평균 속도(json `v_eff_to_top_m_per_ns`)다.

| 구간 | $d-d_\text{top}$ (cm) |
|---|---|
| PEC h 0 | −3.56 ~ −2.15 |
| PVC h 0 | −3.36 ~ −2.11 |
| 공기결합 h 0.1 | +1.34, +1.41 |

- 권고: 가스관처럼 보호판을 까는 관종은 "띠 깊이 = 보호판 깊이일 수 있음(관 상단은 더 깊음)"을 `bias_notes` 후보로 올린다. AIHub lpipe에 보호판이 얼마나 섞였는지는 알 수 없다.

## 8. v1.1 추가 — 파형 울림 세트 (감쇠 진동 파형)

### 8-1. 파형 식과 울림 길이의 근거

전류 파형(`inputs/ring_500MHz.txt`, `#excitation_file`, 1 ps 간격, 선형 보간)은 다음과 같다. 이 파일(약 1.1 MB)은 저장소에 넣지 않는다. `make_inputs.py --stage ring`이 생성한다.

$$I(t)=\frac{g'(t)}{\omega},\quad g(t)=e(x)\sin\big(\omega(t-t_s)\big),\quad e(x)=x^{n}e^{\,n(1-x)},\quad x=\frac{t-t_s}{t_p}\ (t<t_s\text{이면 }0)$$

- 값: $\omega=2\pi\cdot500$ MHz, $n=2$, $t_p$ = 2.8 ns, $t_s$ = 0.5 ns
- $g$의 도함수를 전류로 쓰면 순전하가 0이 된다(적분 −2.6×10⁻¹⁰, 쌍극자에 정전기장이 남지 않음).
- 포락선 길이: 최대의 0.3 이상인 구간이 6.35 ns(**3.2 $P$**), 0.1 이상인 구간이 9.05 ns(**4.5 $P$**)다(`ring_waveform_info.json`).
- 근거: AIHub 띠 박스 높이는 15–21 px이고, $P_\text{px}$ 중앙이 4.3 px이므로 반송파 4–5 주기다. gain 영상에서 눈에 보이는 구간(약 0.1 이상)을 4.5 $P$로 맞췄다. 실제 장비(NM 32채널) 파형은 모른다(**가정**).

- 치수를 바꿔 다시 돌릴 때: `make_inputs.py --stage conf3d_strong --no-bed --plate-width-rule {fixed|spec|spec200} --plate-top-above-m <m> --plate-flange-m <m> --plate-thick <m> --pipes pec pvc --pols x y --models-tag <tag>` → `run_models.py --stage conf3d_strong_<tag>` → `export.py --stage conf3d_strong_<tag>` → `conf3d_strong_summary.py`. ID에 폭·높이·플랜지가 들어가므로 이전 결과를 덮지 않는다.

### 10-2. 젖은 박층 — 2D 결론은 3D에서 성립

| 모델 | 층/관 진폭비 | 측정 $\Delta_L$ ($P$) | $t_\text{top}-\tau_v$ (ns) |
|---|---|---|---|
| 2D `W_PEC_A10` (TMz) | 2.83 | −0.82 | 2.776 |
| 3D x-편파 | 2.66 | −0.88 | 2.774 |
| 3D y-편파 | 2.90 | −0.93 | 2.896 |

진폭비는 2D 대비 −6 ~ +3 %다. 정답 지연 차는 ≤ 0.12 ns(0.06 $P$), $\Delta_L$ 차는 ≤ 0.11 $P$다. 진폭비 약 3의 강한 층은 3D에서도 그대로다.

### 10-3. 보호판 — "띠 = 판"은 3D에서도 성립한다. 가림은 편파에 따라 다르다

가림 = 판 아래 관 단독 포락선 최대 / 같은 격자에서 판 없는 관 단독 포락선 최대. 판/관₀ = 판 단독 포락선 최대 / 판 없는 관 단독 포락선 최대. 출처는 `export/summary_conf3d_strong_compare.json`이다.

| 형상 (높이 0.3 m) | 관 | 폭 | 가림 3D x / 3D y / 2D | 판/관₀ 3D x / y / 2D |
|---|---|---|---|---|
| 평판 (KGS D+100) | PEC | 0.2 | 8.3 / 24.8 / 7.0 % | 6.9 / 9.3 / 5.1 |
| 평판 (KGS D+100) | PVC | 0.3 | 4.6 / 13.4 / 3.3 % | 12.9 / 11.2 / 9.6 |
| 평판 (KOGAS 폭) | PEC | 0.3 | 3.4 / 12.4 / 2.7 % | 7.3 / 8.7 / 5.6 |

| 평판 (v1.1 폭) | PEC / PVC | 0.4 | 1.5 / 7.0 / 1.2 %, 2.4 / 8.4 / 1.8 % | 6.5 / 7.5 / 5.0, 11.4 / 9.6 / 8.6 |

| **∩ 채널 KOGAS** (D+200, B 0.1) | PVC | 0.4 | **0.6 / 2.4 / 0.4 %** | 11.4 / 9.6 / 8.6 |

| 형상 (높이 0.1 m, KGS 예외) | 관 | 폭 | 가림 3D x / y / 2D | 판/관₀ 3D x / y / 2D |
|---|---|---|---|---|
| 평판 (D+100) | PEC | 0.2 | 2.9 / 20.9 / 3.4 % | 3.7 / 4.6 / 3.3 |
| 평판 (D+100) | PVC | 0.3 | 1.9 / 6.8 / 2.2 % | 8.1 / 7.2 / 7.3 |

- **"띠 = 판" 성립**
  - 판 반사는 가리지 않은 관보다 3.7–12.9배 세다.
  - 판 아래 관 신호는 판 반사의 0.05–4.5 %다. 가장 큰 값은 PEC D+100 높이 0.1 m y-편파의 20.9 % ÷ 4.6 = 4.5 %다.
  - 띠 픽 문턱(0.3 $E_\text{box}$)에 한참 못 미치므로 띠 상단 픽은 어느 3D 칸에서도 관 상단이 될 수 없다.
  - 판 아래 관 단독 응답의 첫 피크 지연은 3.6–6.7 ns다. 가리지 않은 관은 2.91–3.08 ns다. 따라서 판 아래에서 보이는 관 신호는 가장자리 회절이고 관 상단 반사가 아니다(§7-4와 같음).
- **2D 대비 3D**
  - x-편파(전기장이 판 길이 방향, TMz와 같은 편파)의 가림은 2D와 같은 수준이다(0.5–9.9 % 대 0.4–8.2 %).
  - **y-편파(전기장이 판 폭 방향)는 3–10배 덜 가린다(2.4–27 %).** 판 가장자리에서 전류가 끊기는 방향이라 회절이 강하다.
  - 따라서 2D의 "0.1–7 %"는 x-편파 하한 쪽 값이다. 3D 범위는 **0.5–27 %**로 고친다. 판/관₀은 3D가 2D와 같거나 최대 1.8배 크다.
- **채널 대 평판**(같은 폭·높이): ∩ 채널은 평판보다 약 2–6배 더 가린다. 3D x-편파는 4–6배(PEC 0.3 m 6.23, PVC 0.4 m 4.16, PEC 0.2 m 5.06), y-편파는 1.9–3.6배(2.54, 3.56, 1.92), 2D는 4.3–4.6배다(`summary_conf3d_strong_compare.json`에서 평판/채널 가림 비로 재계산).
  - PEC 0.3 m: x 3.4 → 0.5 %, y 12.4 → 4.9 %
  - PVC 0.4 m: x 2.4 → 0.6 %, y 8.4 → 2.4 %
  - KGS 폭 0.2 m: x 8.3 → 1.6 %, y 24.8 → 12.9 %
  - 플랜지가 가장자리 회절 경로를 막는다. 판 반사 세기(판/관₀)는 거의 같다. 띠로 보이는 것은 상판이다.
- **높이 0.1 m 대 0.3 m**(평판 D+100): 판이 관에 가까울수록 x-편파 가림이 커진다(PEC 8.3 → 2.9 %, PVC 4.6 → 1.9 %). 판/관₀은 작아진다(PEC 6.9 → 3.7). 판과 관이 1.5 $P$ 안으로 붙어 띠에서 판 반사와 관 회절이 겹친다.
- 그림
  - `docs/processing/band_top_synthetic_ascan_3d_channel_PEC_W30_G30_y.png`: 위는 판만 / 판+관, 아래는 차이. 차이 최대 0.037 V/m다.

### 10-4. 결론 변화와 인계

- §7·§9의 보호판 결론은 **유지되고 강화**된다.
  - 규격 형상(KOGAS ∩ 채널, 높이 0.3 m)에서 관 신호는 판 없을 때의 0.5–4.9 %, 판 반사의 0.05–0.6 %다. 띠는 판이다.
  - 띠 깊이는 판 윗면 깊이이고, 관 상단은 0.3 m(규격 하한) 이상 더 깊다. 판 높이 규격(0.3 m 이상, 예외 0.1 m 이상)이 그대로 깊이 오차의 하한이 된다. `bias_notes` 문구 후보: "가스관 보호판 아래 관: 띠 깊이 = 판 깊이, 관 상단은 ≥ 0.1–0.3 m 더 깊음(KGS FS451·KOGAS-GSM-2121)".
- 2D "0.1–7 %"는 3D에서 **0.5–27 %**(편파 의존)로 바꾼다. 가림이 가장 약했던 경우는 y-편파(흔한 측선 직교 쌍극자)의 PEC 평판 D+100(0.2 m, 높이 0.1·0.3 m)과 PVC 0.2 m 평판이다(20.9–27.2 %). PVC D+100(0.3 m)은 y-편파 13.4 %다. 그래도 판 반사 대비 ≤ 4.5 %라 판정은 같다.
- 젖은 박층은 3D에서 진폭비·시각이 2D와 일치한다. §7-3 픽 모의를 3D로 다시 할 필요는 없다고 판단한다.
- gpr-processing-expert 인계
  - json·npy·h5 형식은 같다(`export/<id>.json`). 3D는 `component` Ex/Ey다.
  - 정답 칸은 `W3_*` 2개다. `P3_*`·`P2_*`는 §7-4와 같이 `t_top_true_ns`를 관 상단 정답으로 쓰지 않는다. 판 깊이와 관 깊이의 차 보고용이다.
