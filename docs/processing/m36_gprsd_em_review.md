## 2. E1 영점 후보 해석

### 2-1. CR2 잔여 파형: 직접 결합 링잉 잔여인가, 슬래브 바닥인가

**판정: 장비에 고정된 직접 결합(링잉) 잔여가 유력하다. 잠정, B.** 슬래브 바닥은 기각 쪽이지만 완전히 배제하지는 못했다.

근거는 셋이다.

1. **도로 사이 비교(가장 강함)**
   - CR2 잔여의 극값 위치는 1–2, 7–9, 16–18, 25–27이다. 이것이 슬래브가 없는 아스팔트 도로 AR1·AR2 6측선의 앞쪽 RMS 극대 위치와 같다(§1-1).
   - 반대로 같은 시멘트 도로인 CR1은 다른 패턴(13–14, 26–29)이다.
   - 시각이 고정된 파형 $k_i w(t)$의 진폭 $k_i$가 트레이스마다 바뀌면 RMS(t) ∝ |w(t)|다. 그래서 RMS 극대는 w의 극값에 생긴다. 아스팔트 도로들은 측선 평균이 0이라도(평균 제거됨) 같은 w를 가지고 있다는 뜻이다.
   - 도로 구조와 상관없이 같은 시각에 같은 주기(반주기 8–9)로 나타나므로 장비 성분이다.
2. **파형 모양**
   - 슬래브 바닥 반사는 엽이 2–3개인 짧은 웨이블릿이다. Ricker 대조에서 피크 21 샘플 앞 포락선은 2 % 미만이다.
   - 관측 잔여는 다르다. 엽이 5–6개이고, 이웃 엽 비가 0.76–0.89이며, 반주기가 점점 길어지고, 샘플 0에서 포락선이 0.27–0.40이다. 이것은 링잉 열의 특징이다.
   - 시변 게인이 뒤쪽 엽을 키워 감쇠가 덜해 보이는 효과가 섞여 있다(C).
3. **진폭 위계**(C)
   - CR2만 측선 평균이 0이 아니다(0.29–0.35 × RMS, 다른 도로는 ≤ 0.013). 이는 제공처의 평균 제거가 이 측선의 트레이스 집합과 다른 기준으로 이뤄졌다는 뜻이다.
   - 그 차이는 수평으로 일정한 성분 중 진폭이 가장 큰 것, 곧 직접 결합과 지표 반사, 그 링잉이 지배한다. 슬래브 바닥 반사(콘크리트–기층 |Γ| ≲ 0.1–0.15)는 직접 결합보다 한두 자릿수 작다.

시각 정합성: 슬래브 바닥은 지표 뒤 A 10.8–19.9, B 12.8–23.5 샘플에 온다.
- τz ≈ 0이면 16–21과 겹칠 수 있다.
- B-front(τz ≈ −23 … −25)면 −12 … 0에 놓인다. 기록 시작 전이거나 첫 샘플이다.
- 그러므로 슬래브 해석은 τz ≈ 0일 때만 시각이 맞는다. 그 경우에도 근거 1·2가 슬래브 해석에 불리하다.

**결론**: 정체가 직접 결합이든 슬래브든, 16–18(부호)과 19–21(포락선)은 **영점이 아니다**(E1-b).

- 슬래브 바닥이라면 지하 사건이다.
- 포락선 피크 19–21은 링잉 열과 시변 게인이 곱해져 뒤로 밀린 위치다.

## 4. E3 공통 τz 추정과 곡률 편향

### 4-1. τz 식별 실패의 물리

**판정: 확정(A). 이 자료와 이 방법으로는 τz를 식별할 수 없다.**

- 모델은 $\tau=\tau_z+\sqrt{h^2+x^2g^2}$이고 $h=\tau_a-\tau_z$, x는 트레이스 단위다. 산란체마다 g를 자유로 두면 테일러 전개는 다음과 같다.
  $$\tau\approx\tau_a+\frac{x^2g^2}{2h}-\frac{x^4g^4}{8h^3}$$
  - 2차 항은 $g^2/h$만 정한다. τz는 4차 항으로만 들어온다.
  - 픽 잡음이 1–1.5 샘플(엄격 QC)이면 4차 항이 그 이상이어야 정보가 생긴다. 즉 $x g\gtrsim(8h^3\cdot1.5)^{1/4}$이 필요하다. h 60이면 약 40 샘플이고, g 1이면 ±40 트레이스(±1.2 m)다.
  - 추적 한계(70 트레이스)와 QC 최소(한쪽 15 픽)를 보면 평평한 사건(g ≈ 1)은 거의 모두 포물선 영역에 있다.
- 비용 곡선(`D2.profile_total_cost`, 엄격)은 34.60에서 33.94로 **1.9 %만 변하고**, 벽 직전에서 최소가 된다.
  - 벽은 가장 얕은 꼭짓점(25.09)이 만든다. 그 꼭짓점은 **후보 탐색 하한 S_MIN = 20**에서 나온다.
  - 그래서 D2 추정 14.7(계획 QC)·15.5(엄격)는 탐색 범위가 정한 값이고 물리 정보가 아니다.
  - 도로별 추정이 18.6 / 15.5 / 17.8 / −18.8로 흩어지는 것도 약한 식별에서 예상되는 모습이다.
- 결합 방향: 포물선 영역에서는 $\delta_z\propto1/\sqrt{h}=1/\sqrt{\tau_a-\tau_z}$다. 참 τz가 0보다 작으면 τz 0으로 구한 δz는 과대다. 배율은 $\sqrt{(h-\tau_z)/h}$이고, h 40에서 τz −24면 ×1.26, −44면 ×1.45다.
  - D2m 산란 많은 층도 같은 방향이다. τz 0에서 0.0146, −24에서 약 0.0122(선형 내삽), −40에서 0.0106이다.
- 대안: τz는 곡률이 아니라 외부 정보로 정해야 한다. 원본 .mat 헤더, Zhou 2018 본문, 깊이를 아는 표적이 그런 정보다.

### 4-2. R 혼동과 Tx–Rx 간격

**판정: 둘 다 작다. 잠정, A(계산).**

- R: 엄격 QC에서 R 0.05/0.15 m는 τz를 +0.8/+2.3 샘플 옮긴다([SC]). δz 0.012에서 ≤ 0.03 m다. 영점 범위(27–46 샘플)보다 한 자릿수 작다.
  - 곡률 쪽 편향은 [P] 표 B 기준 v′/v ≤ 1.14(D 0.4 m, 얕은 관)다. ×1.4–2를 설명하지 못한다.
- Tx–Rx 간격 s(미상): 곡률 편향 v′/v는 s 0.1 m에서 ≤ 1.004, 0.2 m에서 ≤ 1.016, 0.4 m에서 ≤ 1.067(d 0.3 m)이다. d ≥ 1 m에서는 ≤ 1.016이다(§1-4). 무시할 수 있다.
  - s가 더 크게 작용하는 곳은 영점이다. 직접 결합 피크와 송신 시각 사이 지연이 s에 따라 0.3–4 ns가 된다. 이것은 §2-2 범위에 반영했다.

### 4-3. 곡률을 평평하게 만드는 편향이 0.020–0.030을 설명하는가

**판정: 설명한다. 편향 방향은 위쪽 한쪽이고, 계획 QC에서는 크기도 맞는다. 잠정, B.**

- **한쪽 원리**
  - 영오프셋 단면에서 사건의 기울기는 ≤ 2/v다(회절 점근선). 회절 쌍곡선은 주어진 v에서 가장 가파른 사건이다.
  - 다음 요인은 모두 사건을 **평평하게** 만들어 δz를 키운다: 볼록 물체(R > 0), 비스듬한 선형체(v/sinθ), 평평한 윗면을 가진 유한 물체, 기복이 있는 층 경계(곡률이 속도와 무관한 반사 사건), 엽 건너뛰기 픽.
  - 반대로 오목한 경계(굴착 바닥 등)는 꼭짓점을 더 굽게 만든다. 그러나 고립된 쌍곡선형 사건으로는 드물다.
  - 따라서 자동 픽 δz 분포는 위쪽으로 치우친다. 정보는 분포의 아래쪽에 있다.
- **크기**
  - 비스듬한 선형체: 방향이 고르게 퍼져 있으면 중앙값 ×1.414다. 계획 QC 0.0203 / D2m 0.0146 = 1.39와 거의 같다.
  - 엄격 QC 0.0305(×2.09)는 θ ≈ 28°가 중앙값이어야 한다. 엄격 조건(한쪽 15 픽 이상, 단조 계단 ≤ 0.5, 긴 매끈한 날개)이 날개가 긴 평평한 사건을 고르는 선택 편향이 더해진 것으로 본다(추정).
  - 유한 크기 물체: 윗면 반폭 0.1 / 0.2 / 0.3 m는 ×1.26 / ×1.68–1.71 / ×2.0(±0.6 m 구간)이다.
  - 영점: 참 τz가 −24 … −44면 τz 0에서 구한 값에 ×1.1–1.45가 더해진다(§4-1).
  - 이 요인들을 합치면 0.020–0.030(0.0146의 ×1.4–2.1)을 무리 없이 설명한다.
- 추적기 자체의 편향은 없다. 합성 점검에서 |g 오차| ≤ 1.5 %였다([SC] §3-3).

### 4-4. 이동 초점 0.0146 [0.0115, 0.0186]의 타당성

**판정: 물리적으로 타당하다. 다만 위쪽에 가까운 추정이다. 잠정, B.**

- 방법
  - 일정 속도 Stolt 이동 초점은 합성에서 g를 −1.1 … +2.1 % 안으로 복원했다.
  - 산란 많은 창(초점 이득 상위 사분위)에서는 진짜 회절 에너지 비중이 커서 평평한 사건의 영향이 줄어든다(초점 지표는 에너지 가중).
  - 비스듬한 선형체도 v/sinθ에서 초점이 맺히므로 혼합 편향은 여전히 위쪽이다. 그래서 τz 0에서 참 δz는 약 0.0146 이하일 가능성이 크다.
- 격자 끝 창 제외의 정당성: 상위 사분위 55창 가운데 18개가 가파른 끝(g 5)이고 5개가 평평한 끝(g 0.5)이었다.
  - g 5 → δz 0.006은 εr A 57 / B 41이다.
  - g 0.5 → δz 0.06은 A에서 v 0.40 m/ns > c다.
  - 둘 다 비물리 값이라 빼는 것이 맞다.
- 물리 범위
  - 0.0146은 v A 0.097 / B 0.114 m/ns, εr A 9.6 / B 6.9다. 포장·기층의 전형 범위다.
  - 하한 쪽: 습윤 노상 εr ≤ 25로 잡으면 δz ≥ A 0.0091 / B 0.0077이다.
  - 종합하면 τz 0에서 δz는 약 0.008–0.0146이고, τz가 음수면 0.0106–0.0125로 내려간다. 0.012는 가운데에 있다.
- 조건: 곡률 δz는 모두 Δx에 비례한다. Δx가 2 cm면 모든 값이 2/3배가 된다([SC] C5).

### 4-5. 포장·기층 RMS 속도 효과

**판정: 크기 1–8 %. 확정(계산, A). 층 구조는 가정이다.**

- 작은 오프셋의 곡률은 v_rms에 대응한다. 깊이 환산에 필요한 값은 v_avg다.
- §1-4 예시에서 비는 1.002–1.079다. 일반 포장은 1–2 %, 강한 대비(아스팔트 εr 5 / 노상 εr 25)는 ≤ 8 %다.
- 곡률 δz는 깊이 평균 δz보다 ≤ 8 % 크다. ×1.4–2를 설명하지 못한다.
- 이 구간 크기에서 비쌍곡선 항은 2차 효과다.

    a = np.asarray(a, float) - np.mean(a)
    b = np.asarray(b, float) - np.mean(b)
    return float((a * b).sum() / math.sqrt((a * a).sum() * (b * b).sum()))

    h = np.zeros(nn)
    h[0] = 1

    h[nn // 2] = 1
    return np.abs(np.fft.ifft(X * h))[:n]

    for surf in (0.10, 0.05):
        dc = surf * n_rec - cut_front
        dtv = DT["A"] if hyp == "A" else DT["B"]
        K[f"{hyp}_surface{int(surf * 100)}pct"] = {
            "direct_peak_sample": round(dc, 1),
            "tau_z_range_(peak-1.0ns..peak-0.5ns)": [round(dc - 1.0 / dtv, 1), round(dc - 0.5 / dtv, 1)],
            "quiet_samples_expected_before_direct": max(0, round(dc - 0.5 / dtv, 1)),
        }
out["K_zero_hypotheses"] = K
out["K_eps_r"] = {}
for tzv, dzv_ in ((-24.0, out["H_tauz_dz"]["dz_at_-24.0"]), (-44.0, out["H_tauz_dz"]["dz_at_-44.0"]),
                  (0.0, out["H_tauz_dz"]["dz_at_0.0"]), (13.0, out["H_tauz_dz"]["dz_at_13.0"])):
    out["K_eps_r"][str(tzv)] = {h: round((C * DT[h] / (2 * dzv_)) ** 2, 2) for h in DT}

OUT.write_text(json.dumps(out, ensure_ascii=False, indent=1), encoding="utf-8")
