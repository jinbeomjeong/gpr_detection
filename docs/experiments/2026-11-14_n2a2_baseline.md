# 검출 기준선 N2-a′ (YOLO11m, 문맥 이동 증강) — 요약 (2026-11-14)

M1-10 기준선([`2026-11-01_m110_baseline.md`](2026-11-01_m110_baseline.md))을 **대체**하는 검출 기준선이다. 사용자 결정 N6-a(2026-11-14)로, 사전 등록된 채택 판정(A1 충족 + D1 A2 충족)대로 교체했다. **판정 지표는 crop 단위 `last.pt` 전체 mAP50의 fold 평균**이다(M1-10과 같은 정의). test는 M4-3까지 봉인했고 이 문서에는 test 수치가 없다.

- 채택 근거: A1 [`m31_n2a2_a1_judgment.md`](m31_n2a2_a1_judgment.md), D1 r4·A2·채택 [`m31_n2a2_d1r4_judgment.md`](m31_n2a2_d1r4_judgment.md), 계획 [`m31_n2a2_retrain_plan.md`](m31_n2a2_retrain_plan.md) v1.1(학습 봉인 fa4b91c, D1 r4 부록 b4a791f), 증강 [`augmentation_policy.md`](augmentation_policy.md)(2026-11-14 개정).
- 경위: M3-1 검출 입력(L1) 타일 판정 [`m31_detection_input_tiling.md`](m31_detection_input_tiling.md) §8-5(M1-10 위치·축척 민감) → N2-a(§8-6, 불채택) → N2-a′(채택).
