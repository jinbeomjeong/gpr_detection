# M1-7 증강 강도 비교 — 판정 (2026-10-30)

사용자 정의 증강 4종(가우시안 잡음·대비/감마·수평 띠 잡음(ringing)·트레이스 누락)의 강도(`augment_strength`) 0/0.5/1/2를 같은 조건으로 학습해 비교했다. 판정 규칙(`docs/CHECKLIST.md` M1-7, 2026-10-29 결정): **관로 2클래스(pipe_hyperbola·pipe_band) AP50 평균이 가장 높은 강도, 차이가 1 %p 안이면 약한 강도**. 전체 mAP50도 보고한다.

### 재평가 방법
- **가중치: `last.pt`(30 epoch 끝)를 4회 모두 사용.** `best.pt`는 Ultralytics가 fold 0 val의 mAP50-95(이 버전 fitness 가중치 [0,0,0,1])로 고른 epoch라, 판정에 쓰는 같은 분할로 모델을 고른 셈이 되어 낙관 편향이 생기고, 고른 기준(mAP50-95)도 판정 지표(관로 AP50)와 다르다. `last.pt`는 고정 epoch 예산이라 4회가 같은 조건이다. `best.pt` 결과는 민감도 확인용으로만 부록에 둔다(best epoch: 강도 0 → 26, 0.5 → 20, 1 → 26, 2 → 29).
- **기준 집계: crop 단위**(`dataset_spec_m1.md` §4 항목 3 "평가는 crop 단위 1회 집계 기준, 이미지 단위도 함께 보고"). crop마다 gain 사본 하나(1.0 > 0.5 > 0.25 우선; 1.0 1,160·0.5 130·0.25 8)를 고른 1,298장. 이미지 단위(학습 중 val과 같은 3,525장)도 함께 낸다.
- 설정: `model.val(imgsz=256, batch=64, conf=0.001, iou=0.7, split=val)`, 1채널 데이터 yaml(`runs/detect/_data/m17_aug<s>.yaml`). 이미지 단위 `last.pt` 강도 0의 mAP50 83.52 %는 results.csv 마지막 행 83.48 %와 일치(차이 0.04 %p).
- 검증 인스턴스 수(crop / 이미지): pipe_hyperbola 71 / 185, pipe_band 966 / 2,649, cavity 365 / 986, manhole 408 / 1,118.
- 재평가 출력: `runs/detect/m17_eval/yolo11m_aihubv1_20261030_fold0_aug<s>_<last|best>_<crop|img>/`(혼동 행렬·PR 곡선 PNG 포함).

## 4. 판정 — 최적 강도 **0**
1. crop 단위 관로 평균 최고는 강도 0(78.10 %).
2. 1 %p 안에 드는 후보: 강도 0.5(77.73 %, −0.37 %p). 강도 2(−3.55 %p)·1(−6.72 %p)은 밖.
3. 1 %p 안 후보(0, 0.5) 중 약한 강도 → **0**.
4. 이미지 단위로도 결론이 같다: 최고는 0.5(77.14 %)지만 0(76.68 %)이 0.46 %p 안이라 약한 쪽 0. `best.pt` 민감도(부록)에서도 crop 단위 최고가 0(76.93 %)이다.
5. 전체 mAP50(crop)도 0이 최고(84.35 %), 0.5는 −0.63 %p, 2는 −1.27 %p, 1은 −3.62 %p.

**해석.** 사용자 정의 증강 4종은 이 조건(fold 0·30 epoch·단일 시드)에서 관로 AP50을 올리지 못했다. 강도 0과 0.5의 차는 잡음 수준이고, 강도 1의 하락은 주로 pipe_band(59.1 → 48.7 %)에서 나온다. 다만 강도 2가 강도 1보다 높아(관로 평균 +3.2 %p) 강도에 따른 단조 감소가 아니므로, 강도 1의 하락폭 일부는 실행 간 변동으로 보아야 한다. pipe_hyperbola는 crop 단위 인스턴스가 71개뿐이라(1개 ≈ 1.4 %p 재현율) 클래스 AP 차이를 크게 해석하지 않는다.

## 6. 한계
- **fold 0·seed 0 단일 실행.** 실행 간 변동을 재지 않았다. 강도 1 < 2의 비단조성으로 보아 관로 평균의 실행 간 변동은 수 %p일 수 있어, 0과 0.5의 차(0.37 %p)는 구분되지 않는다. "증강이 해롭다"는 결론은 이 데이터로 내릴 수 없고, "이 조건에서 이득이 보이지 않는다"까지만 말한다.
- 판정 규칙(1 %p, 약한 쪽 우선)은 사전에 정한 대로 적용했다. 검증 분할(fold 0)을 강도 선택에 썼으므로, 이 fold의 수치를 최종 성능으로 쓰지 않는다(최종은 5-fold 평균, test 1회).
- AIHub 도메인만 평가했다. 증강의 목적(실측 4TU·GPR-SD 잡음·트레이스 누락에 대한 견고성)은 교차 도메인 평가(M3-3)에서만 드러날 수 있다. 강도 0 채택이 실측 견고성을 해칠 가능성은 이 실험으로 판단할 수 없다.
- pipe_hyperbola 검증 인스턴스가 crop 단위 71개로 적다.

## 7. 5회째(ringing만 끔) 권고 — 사용자 결정(2026-10-30): **C. 시드 반복**
강도 0·1을 seed 1로 한 번씩(`runs/detect/m17_aug0_s1`, `m17_aug1_s1`, 러너 `runs/logs/m17_seed1_runner.ps1`) 돌려 실행 간 변동을 잰다. **실행은 보류**(사용자 결정 2026-10-30, 미실행·예약 없음): 재요청 시 `pwsh -NoProfile -File runs/logs/m17_seed1_runner.ps1`로 시작하고, M1-10 러너와 GPU가 겹치지 않게 한다. 결과는 이 문서에 추가한다. 아래는 결정 전 검토한 선택지다.
최적 강도가 0이라, 원래 계획("최적 강도에서 ringing만 끔")대로 하면 강도 0의 ringing 진폭이 이미 0이어서 **`m17_aug0`과 같은 실험**이 된다. 선택지:

| 선택지 | 내용 | 비용 |
|---|---|---|
| A. 생략 | 강도 0 확정, M1-7 종료 | 0 |
| B. 강도 1에서 ringing만 끔(권고) | 강도 1의 pipe_band 하락이 ringing(수평 띠 잡음 ↔ pipe_band 혼동 가설) 때문인지 확인. `m17_aug1`(pipe_band 48.7 %)·`m17_aug0`(59.1 %)과 비교. 단, 단일 시드 변동이 수 %p라 차이가 작으면 결론을 못 낸다 | 약 16분(30 epoch × 약 30 s + 시작 오버헤드) |
| C. 시드 반복 | 강도 0과 1을 seed 1로 한 번씩 더(실행 간 변동 측정) | 약 32분 |

B 명령(마스크 0xFF, `configs/train_yolo11m_noringing.yaml`의 epochs 3·batch 32·strength 1.0은 인자로 덮어씀):
```powershell
pwsh -NoProfile -File scripts/ops/run_m17_sweep.ps1 -Strengths 1 -Epochs 30 -Batch 64 -Workers 2 -Mask 255 -Prefix m17 -Suffix _noring -Config configs/train_yolo11m_noringing.yaml
```
출력 `runs/detect/m17_aug1_noring`, 로그 `runs/logs/m17_aug1_noring.log`. 시작 전 GPU가 비어 있는지, 코어 0–7이 다른 세션 예약과 겹치지 않는지 확인한다. 재평가는 이 문서와 같은 방법(`last.pt`, crop 단위)으로 한다.
