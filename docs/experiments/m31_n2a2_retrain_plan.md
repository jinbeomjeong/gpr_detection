- 상태: **초안 v0.1** (2026-11-13, cv-detection-expert). 사용자 결정 N5-a(2026-11-13)에 따른 계획이다. 학습·코드 수정은 하지 않는다. 맥락 출처(§2)와 §8 사용자 결정이 정해진 뒤 v1.0으로 봉인한다.

## 1. 문제 정의 — 무엇을 학습시켜야 하나

- 실제 측선 안쪽 타일에서 객체는 소유 구간(50 % 겹침 ±64, 75 % ±32 px) 어디에나 놓이고, **옆은 채움이 아니라 실제 B-scan**이다. D1의 X6가 이 상황에 가장 가깝다.
- AIHub 학습 crop은 객체가 가로 중앙 ±12 px에 몰려 있다. crop 밖 맥락이 없으므로 "중앙에서 벗어난 객체 + 실제 옆 맥락"을 만들려면 **crop 바깥의 실제 열**이 필요하다.

### 2-3. 권고

1. **gpr-dataset-curator에 (b) 확인을 맡긴다**(위임 필요). AIHub 71327 원천 zip(TS_/VS_ B scan, 그리고 C-scan·기타 원천)에 crop 이전 세션 B-scan(또는 crop을 다시 만들 수 있는 원자료)이 있는지, 있다면 다음을 알려 달라.
   - 형식
   - crop `x(a-b)`와 열 정합
   - gain 처리 단계
   - 세션당 크기
   - 라벨 범위(crop 밖 객체 라벨 유무)
2. (b)가 있으면 (b)를 주 맥락 출처로 쓴다(사용자 결정 U2-a).
3. (b)가 없으면 **(c1) + (a)**를 쓴다. (c1)이 모든 클래스의 기본이고, (a)는 겹친 crop이 있는 경우(주로 pipe_band)에 확률적으로 쓴다. 이 경우 §5-2의 독립 시험을 반드시 둔다.

## 3. 증강 설계 (맥락 출처 미정 상태의 공통 틀)

| 단계(순서) | N2-a | N2-a′(초안) | 이유 |
|---|---|---|---|
| 등방 축척(프로젝트) | U[0.55, 1.5], 확률 1, 축소 AREA·확대 LINEAR, 위·가로중앙 | 같음. 단, 확대 때 가로 crop 창 위치를 중앙 고정이 아니라 **문맥 이동 단계에 넘긴다** | 확대 영상의 남는 폭을 맥락으로 쓰기 위해서다 |
| **문맥 이동**(신규) | 없음 | 확률 0.6. dx를 U[−96, 96]에서 뽑되, **실제 맥락이 있는 범위로 자른다**. 맥락은 (b) 원본 → (a) 이어 붙인 측선 → (c1) 확대 여유 순서로 찾는다. 맥락이 없으면(축소·원본 없음) 이동하지 않는다 | 채움 없이 객체를 중앙에서 벗어나게 하는 유일한 방법이다 |
| 채움 이동(N2-a 가로 이동) | 확률 0.5, ±96, 채움 128 | **확률 0.15**, ±96, 채움 128 | 측선 끝·짧은 측선의 실제 채움을 재현하되, "이탈 = 채움" 상관을 약하게 한다 |
| 가장자리 채움 띠 | 확률 0.3, 좌·우 8–96 / 아래 16–128 | **확률 0.15**, 크기 같음 | 채움 띠 손실(11.6 %p)은 남아 있지만 실제 내부 타일에는 옆 채움이 없다. C′ 아래 채움(4TU 타일의 37–69 %)은 계속 학습해야 하므로 끄지 않는다. 아래 띠 비중을 0.5로 올린다(좌 0.25 / 우 0.25 / 아래 0.5) |
| 가려진 박스 규칙 | 넓이 ≥ 50 %, 잘린 박스만 변 ≥ 4 px, 단계 전 프레임 자르기 | 같음. 맥락 영역의 다른 객체 라벨도 같은 규칙으로 넣는다((a)는 겹친 crop 라벨 합침, (b)는 원본 라벨) | 맥락 안의 실제 객체를 배경으로 학습시키지 않기 위해서다 |

- 확률 값은 초안이다. 사용자 결정 U2-b에서 확정한다.
- 금지 증강(상하 반전·큰 회전·전단·원근·세로 비율 리사이즈)과 mosaic 금지는 그대로다.
- (a) 이어 붙이기의 밝기 맞춤(사전 확정 규칙): 겹침 열에서 두 crop의 평균·표준편차를 맞춘다(선형 이득·오프셋, 겹침 구간 최소제곱). 겹침 상관 < 0.98이면 그 쌍은 쓰지 않는다.

## 5. 평가

### 5-1. A1·A2·채택

[P] §3-1과 같다. A1은 AIHub 원 crop(M1-10과 같은 평가)이고, A2는 D1 r4 규칙 O, 채택 = A1 그리고 A2다.

### 5-2. D1 r4와 학습 밖 시험 (보고 전용, 판정 조건 아님)

- D1 r4는 [T] v0.5.2 규칙을 그대로 쓴다. 문맥 이동은 X6(확대 + 창 이동)와 같은 종류의 변환이다. 그래서 X6 개선은 "학습에서 본 변환에 대한 강건성"에 가깝다. 이 한계를 판정서에 공개한다([T] §8-6 (4)와 같은 방식).
- **학습 밖 시험(보고 전용)**: 학습에 쓰지 않은 실제 맥락에서의 위치 민감도를 따로 잰다.
  - (R1) 겹친 crop 쌍의 겹침 구간을 이용한 "실제 이동"이다. 같은 객체가 crop A에서는 중앙, crop B에서는 겹침만큼 옆에 있다. 두 crop에서의 재현율 차를 객체 단위로 짝지어 잰다. 검증 fold만 쓰고, 학습 변환(리샘플·채움)이 없다. 대상은 주로 pipe_band이고, 쌍곡선은 수십 개 규모라 표본이 작다.
  - (R2) (b) 원본이 있으면, 검증 fold 세션 원본에서 객체 주변을 dx ±32·±64로 잘라 잰다.
  - 이 값으로 판정하지 않는다. 판정을 바꾸려면 새 사전 등록이 필요하다(사용자 결정 U2-c).
- M3-3·D3(실측 4TU)가 최종 확인이다.

## 6. 누수 점검

- 맥락은 그 crop과 **같은 세션(`source`)·같은 채널·같은 gain**에서만 가져온다. train_pool에서 fold를 넘는 세션은 0개이므로, 같은 세션 맥락은 같은 fold 안에 머문다.
- 학습 fold의 맥락은 학습 fold 세션에서만 온다. 검증 fold 세션의 crop·원본은 학습 증강에 쓰지 않는다. 구현이 fold 매니페스트로 이를 단언한다.
- test 세션(홀드아웃)은 학습·검증·맥락 어디에도 쓰지 않는다. (b) 원본에서도 test 세션 파일은 읽지 않는다. 경로나 세션 목록으로 거부한다.
- (a)·(b)의 맥락 영역에 다른 crop 라벨이 있으면, 그 crop도 같은 세션이어야 한다(자동 충족). 라벨이 없는 객체가 맥락에 보일 위험은 (b)에서 크다. curator 확인 항목에 넣는다.
- gain 사본은 같은 gain끼리만 잇는다. 서로 다른 gain을 섞으면 밝기 규칙이 깨진다.
