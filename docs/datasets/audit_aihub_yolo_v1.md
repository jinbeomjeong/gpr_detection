## pHash 근접 중복

방법: imagehash `phash`(64 bit), 같은 gain끼리 전수 쌍(약 5,600장 × 3 gain). 같은 gain끼리만 보는 이유는 gain 사본이 서로 비슷한 것이 정상이기 때문이다.

| 해밍 거리 | 전체 쌍 | 같은 세션 | 분할 경계를 넘는 쌍 | test↔pool |
|---|---|---|---|---|
| = 0 | 15 | 12 | 3 | 0 |
| ≤ 2 | 86 | 62 | 21 | 3 |
| ≤ 4 | 318 | 181 | 117 | 39 |
| ≤ 8 | 4,082 | 965 | 2,672 | 756 |

- 경계를 넘는 쌍은 전부 **세션이 다르다**(세션 단위 분할이므로 세션 키 누수는 아니다). ≤ 2에서 경계 쌍 21 중 18이 맨홀-맨홀, 대부분 `MA_2016…` 세션끼리다. 같은 현장을 날짜만 달리 측정한 맨홀 반복 스캔이거나 거의 빈 배경 이미지일 가능성이 있고, 육안 확인은 하지 않았다. 해밍 ≤ 8은 느슨한 기준이라 배경 유사성도 포함된다.
- 쌍 목록: `analysis/data/out/phash_pairs_le8.csv`, `analysis/data/out/phash_cross_le4.csv`.

## 알려진 한계 (경고 사유)

1. **pipe 세션 수가 극소**: 전체 tpipe 11세션·lpipe 13세션. test는 각 2세션(둘 다 `NM_2022-10-19_(12_47_20)` 공유), fold별 tpipe는 3/2/1/1/2세션, lpipe는 2/1/2/4/2세션이라 fold 간 pipe 지표 분산이 크고 fold2·fold3의 tpipe는 단일 세션, fold1의 lpipe는 단일 세션이다. 검증 결과는 세션 한두 개에 좌우된다. 부수 결과로 fold3 lpipe는 112장에 그친다.
2. **클래스 균형 샘플링**: pipe 수에 맞춰 cavity·manhole을 줄였다. test 분포도 균형이므로 정밀도(precision)는 실제 분포보다 낙관적으로 나온다. 자연 분포 평가는 별도 필요.
3. **pHash 경계 근접 중복**: ≤ 2에서 21쌍(test↔pool 3쌍)이 존재(세션은 다름). 점수 해석에 영향이 작지만 0은 아니다.
