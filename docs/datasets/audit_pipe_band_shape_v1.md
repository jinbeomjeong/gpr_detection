# pipe_band 박스 형상·일관성 감사 (aihub_yolo_v1)

- 작성일: 2026-10-30
- 대상: `data/aihub_yolo_v1/labels`(YOLO txt, 256×256 JPG), 매니페스트 `data/splits/aihub_yolo_v1.csv`(seed 20261029)
- 분석 스크립트: `analysis/data/audit_pipe_band_shape.py`(통계·쌍 분석), `analysis/data/audit_pipe_band_shape2.py`(세션별 조각남·병합 모의·예시 그림). 중간 CSV는 `analysis/data/out/pipe_band_*.csv`.
- 원본 zip·XML은 열지 않았다(파생 YOLO 데이터와 매니페스트만 읽음). 원본 불변 증명 도구는 쓰지 않았다(원본 접근 없음).
- 단위: **crop_key당 1장**으로 묶었다(gain 0.25/0.5/1.0 사본 제외, 대표 = gain 1.0). 6,243개 crop 중 사본이 2장 이상인 6,082개 crop에서 **gain 사본 간 라벨이 모두 동일**함을 확인했다(차이 0건). 수치는 crop 이미지·박스 기준이며 전체 이미지 장수(16,887)가 아니다.
- 범위: 균형화된 v1 데이터(관로 이미지 pool 4,933장 + test 695장 기준, `audit_aihub_yolo_v1.md`) 안의 pipe_band, 즉 train_pool 5-fold + test. 데이터 전체(AIHub lpipe 6,193 객체)가 아니다.

- pipe_band는 "전폭 띠"가 아니다. 폭 중앙값이 이미지 폭의 40 %이고 전폭 박스는 2.5 %뿐이다. 가장자리 접촉 33 %는 crop 경계에서 잘린 띠로 읽힌다(좌우가 거의 대칭).
- pipe_hyperbola는 이미지당 박스 1개, 크기가 매우 균일하다(w 중 96.5 %가 0.1–0.25 폭). band와 hyperbola의 종횡비 분포는 거의 분리된다(hyperbola p95 2.3 < band p5 3.2).
- 깊이(박스 중심 y, px): band p5/p50/p95 = 54 / 66 / 88, hyperbola 44 / 59 / 80. 둘 다 지표 근처(상단 1/3)에 몰려 있다.
- pipe는 전부 NM(32채널) 장비이므로 장비별 비교는 성립하지 않는다(band 13세션·hyperbola 11세션 모두 NM).

같은 이미지 안 pipe_band 박스 쌍 1,030개를 분석했다. "같은 깊이" = y 겹침이 작은 박스 높이의 50 % 이상.

- 간격 ≤ 8 px 쌍이 **403개 이미지(26.5 %)**에 있다. 한 층을 이어 붙여 그린 라벨이 몇 px 틈으로 끊긴 형태로 읽힌다(몽타주 예시: `figures/pipe_band_shape/pipe_band_examples.png` 첫 두 칸). 간격 > 32 px 쌍은 같은 띠의 약한 구간인지 별개 반사인지 이 감사로는 판정할 수 없다.

## 6. 결론

| 라벨 문제 유형 | 규모 (crop 기준) | 판정 |
|---|---|---|
| 같은 층이 간격 ≤ 8 px로 끊긴 조각 라벨 | 이미지 403장(band 이미지의 26.5 %), 이 병합으로 박스 −21 % | **실제 문제, 가장 큼** |
| 간격 8–32 px / > 32 px 조각 | 99쌍 / 124쌍 | 판정 불가(같은 띠인지 별개인지 시각 확인 필요) |

| 형상 퇴화·극단 크기(w < 16 또는 h < 4) | 0 | 문제 없음 |

**M1-10·평가 해석에 주는 영향**
- 조각난 GT가 band GT의 약 절반(1,143/2,279 박스가 조각난 이미지에 속함)에 걸려 있으므로, 모델이 연속 띠 하나로 예측하면 IoU 0.5를 못 넘는 조각 GT를 놓치고 반대로 조각별로 예측하면 이웃 조각 사이 예측이 FP로 센다. band AP50 49–59 %의 상한을 낮추는 **라벨 쪽 원인 후보**다(모델 예측과 대조해 확인하지는 않았다).
- fold 0 band 점수는 한 세션(934박스, 54 % 조각남)이 좌우하고 fold 3은 62박스뿐이라, band의 fold 평균·fold 간 비교는 세션 편향이 크다. 폴드 평균에 band를 넣을 때 표본 한계를 함께 적어야 한다.
- 전폭 띠 가정(깊이 추정에서 띠 상단 경계 사용)에는 영향이 있다. 라벨이 조각나 있으면 "띠 상단 경계"를 박스 하나에서 못 읽을 수 있다.

**권고**
1. 박스 병합 규칙을 후보로 둔다: 같은 이미지·같은 클래스에서 y 겹침 ≥ 50 % 이고 x 간격 ≤ 8 px(보수적) 또는 ≤ 16 px이면 하나로 합침. 8 px 병합은 박스 −21 %, 단일 박스 이미지 비율 64 → 84 %가 된다. 병합 데이터(`aihub_yolo_v2` 등 새 버전)를 만들되 **원본 v1은 보존**하고, 합쳤을 때 mAP가 오르는지는 cv-detection-expert가 같은 fold로 비교한다.
2. 간격 > 8 px 쌍(223쌍)은 자동 병합하지 말고 소수를 시각 검토(최대 30장 정도)해 규칙을 정한다. 재라벨 대상은 조각남 비율이 높은 세션(NM_2022-09-22_(11_10_46), 10-19 (12_33_02)·(12_47_20)·(11_03_51), 11-02 (14_16_20))이다.
3. 평가에서는 band를 별도 보고한다: 세션별(또는 fold별) AP50, 병합 전후 GT 두 가지 AP, 가장자리 접촉 박스 제외 AP.
4. fold 3의 band 62박스는 보고서에 표본 한계를 명시한다(fold 구성은 ADR-003 결정이라 이 감사는 바꾸지 않는다).

## 핸드오프

- **위임 필요(cv-detection-expert)**: 위 병합 전후 AP 비교, band AP50의 fold별·세션별 분해, 평가 시 band 별도 보고 방식, M1-10 판정에서 band의 가중 결정.
- **위임 필요(python-expert, 명세)**: `scripts/build_*` 변환 단계에 선택 옵션 `--merge-band-gap <px>`(기본 0 = 병합 안 함)를 추가. 같은 이미지·같은 클래스 1에서 y 겹침 ≥ 0.5 이고 x 간격 ≤ G이면 합집합 박스로 대체(반복 병합, 결과가 안정될 때까지). gain 사본은 같은 결과가 되어야 한다. 출력은 새 버전 폴더 `data/aihub_yolo_v2/`, 병합 개수 로그와 제외 목록을 남긴다. 분할·매니페스트는 v1과 동일.
- **사용자 조치 필요**: 간격 > 8 px 쌍 일부와 조각남 상위 세션 이미지 시각 검토(재라벨 여부 결정).

## 한계

- 모델 예측이 없어 조각난 라벨이 AP에 얼마나 기여하는지는 측정하지 않았다(가설 단계).
- 이 데이터는 pipe 균형화(695장 목표) 후의 부분집합이다. 전체 lpipe 객체(6,193)의 조각남 비율과 다를 수 있다.
- 이 감사는 원본 XML을 읽지 않았다. 조각남이 원본 XML 단계의 것인지 변환 과정(crop 절단)에서 생긴 것인지는 구분하지 않았다. gain 사본 간 라벨이 동일하고 간격이 2–4 px로 거의 붙어 있는 점에서 원본 라벨의 성질일 가능성이 있으나, 변환 단계 기원 여부는 원본 XML 대조(미수행)로만 확정된다.
- 이 실행은 CPU 경합 때문에 BelowNormal로는 진행되지 않아 Normal 우선순위로 단일 프로세스를 실행했다(각 스크립트 수 분 이내).
