## 1. 한 줄 요약

시멘트 도로 2곳·아스팔트 도로 2곳을 200\~400 MHz GPR로 각각 평행 3측선씩 탐사한 B-scan 12개(측선당 약 280\~830 m, 합계 약 8.3 km)와, 관로·공동·이완층·균열 위치를 대략 표시한 표(Mark.xlsx, 73건)입니다. 원본은 MATLAB .mat이고 위치표는 빈 셀을 위 행에서 이어 읽어야 하는 엑셀입니다. 이 가공본은 ① .mat을 npy/png로 바꾸고, ② 위치표를 CSV로 정리하고(도로 이름 통일·오타 정정·구간 불일치 표시), ③ 표식 위치를 그림에 겹치고, ④ 박스 라벨 작업용으로 표식 주변 ±150트레이스 창을 따로 잘라 둔 것입니다.

가장 큰 가치: 실제 도로에서 연속으로 찍은 장거리 측선과 관로 17건·공동 18건 등 이상체 위치가 있어, 쌍곡선 탐지 모델의 사전학습·약지도 학습·교차 데이터셋 검증에 쓸 수 있습니다. 같은 도로 3측선에 같은 이상체가 반복해 나타나 측선 간 일관성 검사도 가능합니다.

가장 큰 한계: 표식은 **트레이스 번호 1개뿐**(깊이·폭·박스 없음, 위치 오차 ±50\~100트레이스 = ±1.5\~3 m)이라 그대로는 학습 정답이 되지 못하고, 시간축 눈금·전파속도·안테나 모델이 확인되지 않아 깊이는 거친 추정만 가능합니다. 또 지표 에코 제거·게인이 이미 적용된 후처리 자료입니다.

## 4. 물리 축척 — 반드시 읽을 것

| **항목** | **값** | **상태** |
|---|---|---|
| 트레이스 간격 trace_dx_m | 0.03 m | 원 저장소 문서 값 |
| 시간창 | 97 ns | 문서 값. 파일에는 시간축 정보가 없음 |
| 샘플 간격 | 0.302 ns(가설 A: 321샘플 = 97 ns) 또는 0.255 ns(가설 B: 원래 380샘플 = 97 ns에서 앞 59샘플을 잘라냄) | **미확정, ±16% 차이**. json·CSV에 dt_ns_hypA_321, dt_ns_hypB_380 둘 다 기록 |
| 안테나 | 200\~400 MHz | 문서 값, 모델명·중심주파수 미기재 |
| 전파속도·유전율 | 없음 | — |
| 샘플당 깊이 depth_per_sample_m_rough | 약 0.012 m(1.0\~1.4 cm) | 관로 쌍곡선 맞춤으로 거칠게 추정(적합도 낮음). 시간영점 = 샘플 0 가정이며 가설 B면 약 30% 과대 |
| 전체 깊이 | 321샘플 × 1.0\~1.4 cm ≈ 3.2\~4.5 m | 위 추정의 연장 |

- 그림의 오른쪽 깊이 축은 1.2 cm/샘플로 그린 **거친 참고값**입니다. 정밀 깊이가 필요하면 쌍곡선 맞춤으로 직접 보정하세요
- 표식된 관로의 쌍곡선 꼭짓점은 대부분 샘플 51\~68(대략 깊이 0.5\~1.0 m) 부근입니다
- 진폭은 MATGPR로 지표 에코 제거·게인을 적용한 실수값입니다. 극값이 ±1.4×10⁵까지 가므로 정규화할 때 |진폭|의 99% 백분위 등으로 잘라 쓰세요. CementRoad2는 수평 성분이 일부 남아 있습니다(mean_trace_max_abs)
- npy는 원본 float64를 float32로 저장한 것입니다(상대오차 10⁻⁷ 수준)

## 5. 표식(marks.csv) 해석과 한계

| **열** | **설명** |
|---|---|
| xlsx_row | 원본 Mark.xlsx의 행 번호 |
| road_xlsx / road | 원본 도로 표기(alsphat은 원본 오타) / 파일 이름용 도로 이름 |
| segment_xlsx | 원본 구간 표기(0-5000, 5000-10000, … 25000+) |
| location_trace / location_m | 표식 트레이스 번호 / × 0.03 m |
| type / 유형 / type_xlsx | pipeline·cavity·loose·crack / 한글 / 원본 표기(losse 2건은 loose로 정정) |
| segment_mismatch | 표식 번호가 원본 구간 범위 밖이면 "예"(5건, 원본 오류로 보임 — 트레이스 번호를 우선 신뢰) |
| files | 이 표식이 적용되는 측선 3개 |
| window_png | 표식창 그림 경로({파일}에 측선 이름을 넣음) |

- 원본 표에는 측선 구분이 없어 한 표식이 같은 도로의 측선 3개에 모두 적용되는 것으로 봅니다. 실제로 3측선의 같은 트레이스 번호 부근에 같은 이상체가 나타납니다. 다만 측선마다 트레이스 수가 최대 108개(약 3 m) 달라 정렬은 근사적입니다
- 위치 정밀도: 원 저자도 "대략 표시(roughly marked)"라고 밝혔고, 쌍곡선 꼭짓점과 비교하면 ±50\~100트레이스(±1.5\~3 m) 오차가 있습니다. 표식 1개 근처에 관로 쌍곡선 2개가 있는 경우도 있습니다
- 깊이·폭 정보가 없어 그대로 박스 라벨로 쓸 수 없습니다. 표식창 그림에서 쌍곡선을 찾아 박스를 직접 그리는 작업이 필요합니다
- 균열(crack) 표식은 영상에서 눈으로 구분하기 어려워 신뢰도가 낮습니다. 공동 일부는 물이 찬 공동이라는 원본 주석이 있습니다
- 이 과제(관로 탐지) 관점에서는 관로 17건이 직접 쓸모 있고, 공동·이완층은 지반침하 쪽 참고용입니다

## 6. 사용 예

### 6-1. npy + json으로 읽기

```
import numpy as np, json
D = np.load('05_radargrams_npy/CementRoad1_1.npy')                     # float32 [321 샘플, 트레이스]
p = json.load(open('05_radargrams_npy/CementRoad1_1.json', encoding='utf-8'))
dist = np.arange(D.shape[1]) * p['trace_dx_m']                          # m
depth = np.arange(D.shape[0]) * p['depth_per_sample_m_rough']           # m(거친 추정)
marks = p['marks']                                                      # 이 도로의 표식 목록
```

06_scripts\example_load.py \<패키지폴더\> CementRoad1_1 0을 실행하면 첫 번째 표식 주변 창을 그립니다.

### 6-2. 학습용 입력

- 03_radargrams_png_raw: 파일별 99.5% 진폭으로 정규화한 8비트 그레이(처리 없음). 세로 1 px = 1 샘플, 가로 1 px = 1 트레이스(3 cm). 측선이 길어(최대 27,628 px) 학습 시에는 창 단위로 잘라 쓰세요
- 04_radargrams_png_view는 사람이 보기 위한 그림(축·표식선 포함)이라 학습 입력으로는 쓰지 마세요

## 7. 권장 활용 순서

1. 04 표식창에서 관로(pipeline) 표식 17건 × 3측선을 보고 쌍곡선 위치에 박스 라벨을 그림(소량 검증셋)
2. 같은 도로 3측선에서 같은 이상체가 반복되는 점을 이용해 약지도 학습·측선 간 일관성 검사
3. 쌍곡선 맞춤으로 샘플당 깊이를 보정하는 절차 시험(시간축 두 가설 비교)
4. 광저우대·4TU·모로코 가공본, 국내 AI Hub 자료와 함께 교차 도메인 검증
