## Dataset Summary

서울 도로에서 측정한 3D 지표투과레이더(GPR) 탐사 데이터로, B-scan·C-scan 이미지(JPG)와 객체 박스 라벨(XML)로 이뤄진다. 라벨 클래스는 공동(`cavity`: 대칭·비대칭·기타), 맨홀(`manh`), 종배관(`lpipe`), 횡배관(`tpipe`)이다. 이 프로젝트는 B-scan만 쓴다. AIHub 페이지 기준 2015–2022년 서울 도로 측정, 총 213,474건, v1.1(2023-11-21)이다([prior_art §3](../../research/prior_art.md)). 구축은 셀파이엔씨·아이리스테크놀로지로 표기돼 있다(AIHub 공개 페이지).

## Dataset Structure

### 형식

- 로컬 위치: `C:\workspace\GPR_Data\261.3D 지표투과레이더 탐사 데이터\01-1.정식개방데이터\{Training,Validation}`(zip, 압축 풀지 않고 `zipfile`로 읽음, 읽기 전용).
- B-scan 라벨 zip 12개. 이미지는 전부 256x256x1 JPG이며 `x(a-b)`는 원 B-scan에서 잘라 낸 256열 구간을 뜻한다.
- 파일명 규칙: `<장비>_<날짜>(<시각>)_<채널>_<B번호>_g<gain>_x(<a>-<b>)`. 같은 크롭이 gain 0.25 / 0.5 / 1.0 세 벌로 들어 있다.
- XML 필드: `filename`, `source`(세션), `equipment`, `channels`, `channellayer`, `gainvalue`, `permittivity`, `scanclass`, `roadtype`, `object/name`·`bndbox` 등.

### 분할 (제공 분할은 쓰지 않음)

제공 Validation 세션 1,599개는 **100 %** Training에도 있다(파일명은 겹치지 않지만 gain 제거 크롭 키 7,260개가 겹침). 그래서 합친 뒤 다시 나눈다([ADR-003](../../architecture/ADR-003-data-split-and-classes.md) 결정 2, 명세 [dataset_spec_m1.md](../dataset_spec_m1.md)).

## Dataset Creation

- **출처**: AIHub 「3D 지표투과레이더 탐사 데이터」 dataSetSn=71327 (https://aihub.or.kr/aihubdata/data/view.do?dataSetSn=71327), v1.1 2023-11-21 ([prior_art §3](../../research/prior_art.md)).
- **가공(이 프로젝트)**: B-scan만 사용(C-scan 제외). 이미지는 원본 바이트 그대로 복사(재인코딩 없음). 이미지-라벨 짝은 zip **멤버 이름** 기준. 공동·맨홀은 관로 이미지 수와 비슷한 규모(balance-ratio 1.0)로 세션 균형을 유지하며 축소(가용분의 약 15–20 %).
- **라벨링**: 원 데이터 구축 기관이 만든 박스 라벨(XML)을 그대로 사용했다. 이 프로젝트는 라벨을 고치지 않았다.
- 재생성: `conda run -n gpr-dev python -I scripts/build_yolo_dataset.py` (옵션은 [dataset_spec_m1.md §6](../dataset_spec_m1.md)).

## Considerations (알려진 결함·편향·한계)

1. **XML `<filename>`이 zip 멤버 이름과 다른 경우** 전체 1,870건(`<source>`가 이름 유도 세션과 다른 경우 224건). 짝은 멤버 이름 기준으로 맞춘다. `aihub_yolo_v1`에 포함된 427건 중 418건은 `.jpg` 확장자 유무만 다르고 실제로 이름이 다른 것은 9건(공동)이며, 육안으로 박스가 내용과 맞음을 확인했다(완전한 배제는 아님).
2. **관로 세션이 극소**: tpipe 11, lpipe 13세션, 전부 NM 장비. fold별 관로 지표는 세션 1–4개에 좌우되고 test도 관로 세션이 종류별 2개(같은 날 NM)다.
3. **gain 사본은 독립 표본이 아니다**: 파일 74,838개가 고유 크롭 27,680개. 평가는 crop 단위로 1회 집계하고 이미지 단위 값도 함께 낸다.
4. **클래스 균형 축소**: test도 균형 표본이라 precision이 자연 분포보다 낙관적이다.
5. **분할 경계의 근접 중복**: pHash 해밍 ≤ 2 쌍 86개 중 21개가 분할을 넘는다(test↔train_pool 3개). 모두 세션이 달라 세션 키 누수는 아니다.
6. **혼합 클래스 32장**(lpipe+manhole)은 두 NM 세션에 있다.
7. **lpipe 수평 띠**는 지층 경계·직접파 잔여 반사와 구분하기 어렵고, 한 층이 여러 박스로 쪼개진 경우가 있다. 쌍곡선 피팅(깊이)은 tpipe에서만 성립한다.
8. **물리 스케일 없음**: 세로축 ns/px, m/px을 알 수 없다(1차 출처인 활용가이드·데이터 설명서는 로그인 다운로드로 미확인). 이 데이터로는 m 단위 깊이를 내지 않는다. `permittivity` 6.0은 상수라 속도·깊이 계산에 쓰지 않는다.
9. 정보량 없는 필드: permittivity·scanclass·roadtype이 단일값.
