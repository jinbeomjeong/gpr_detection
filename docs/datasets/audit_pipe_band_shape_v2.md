- **해석.** v1 조각 라벨이 조각 FP의 약 37 %만 설명한다. 나머지는 정답이 박스 1개인 crop에서도 나온다. 후보 원인은 (a) 겹치는 이웃 crop과의 라벨 길이 불일치(§5)로 모델이 같은 띠의 서로 다른 구간 길이를 학습, (b) 모델이 긴 띠를 여러 조각으로 예측. (b)는 이 감사가 예측 영상을 보지 않아 검증하지 못했다(cv-detection-expert 갤러리로 확인).
- **정적 모의(재학습 아님).** FP 박스를 병합 정답(간격 ≤ G)과 다시 매칭하면 IoU ≥ 0.45가 되는 FP는 조각 띠 7/10/9개(G = 8/16/32 px), 중복 71/69/69개, 정답 없는 곳 0개다. 병합이 오검출 수를 직접 줄인다는 근거는 약하다. 병합 효과는 새 정답으로 다시 학습·평가해야 알 수 있다(cv-detection-expert).

| 그중 crop 가장자리(≤ 3 px)에 닿음 | 19 (좌우 어느 쪽이든 FP가 "정답 박스 ↔ crop 가장자리" 사이 꼬리) |

- 따라서 이 FP는 모델 환각이 아니라 **라벨 규약("띠는 보이는 구간 전체, 가장자리까지")의 부재**로 보는 것이 맞다. 재라벨 지침에 crop 가장자리 연장을 명시한다.

## 5. 신규 발견 — 인접 crop이 겹치고 같은 띠를 다르게 그렸다

crop은 같은 측선(`..._N00_B<n>`)에서 256 px 폭으로 잘렸고 이웃 crop끼리 **겹친다**(v1 부분집합 안 연속 crop 쌍 1,363개 겹침, 정확히 맞닿은 쌍 0; stride p10/p50/p90 = 19/103/172 px, 공유 폭 p10/p50/p90 = 84/153/237 px). 8쌍에서 이웃 crop을 stride만큼 옮겨 비교하면 평균 절대 화소차가 2–9(/255)라 같은 화소임을 확인했다(`pipe_band_v2_crop_overlap_check.png`, 로컬 전용).

| 항목 | 값 |
|---|---|
| 공유 폭 ≥ 32 px이고 한쪽 이상에 pipe_band 라벨이 있는 이웃 쌍 | 1,207 |
| 그중 양쪽 다 pipe_band 라벨 | 1,179 |
| 한쪽에만 라벨(다른 쪽은 이 구간에 띠 라벨 없음) | 28 (라벨 쪽 커버리지 ≥ 30 %: 24) |
| 양쪽 라벨 쌍의 x 커버리지 불일치(XOR 비율) p50 / p75 / p90 | 0.41 / 0.86 / 0.97 |
| 불일치 > 20 %인 쌍 | 784 / 1,179 (66 %) |

- 같은 화소에서 같은 띠를 라벨러가 crop마다 따로 그려, 같은 구간의 라벨이 일치하지 않는 쌍이 3분의 2다. 단순 비교(행 무시)라 깊이가 다른 층이 섞인 쌍이 있으면 과대평가될 수 있다.
- 이것이 §1의 "단일 박스 crop 안 조각 FP 50 %"와 §2의 큰 세션 간 스타일 차의 한 원인으로 보인다(인과는 미검증).
- 교차 crop 절대 좌표 병합(겹치는 crop의 같은 행 박스를 하나로 합치고 crop에 맞춰 자르기) 모의(`audit_pipe_band_v2_crossmerge.py`): G = 32 px에서 사슬 길이 p50/p90/최대 254/783/2,290 px, 잘라 넣은 박스의 41.5 %가 crop 전폭(≥ 95 %), 높이 팽창 p95 1.53배(최대 2.16배). **자동 적용은 권하지 않는다**(띠 의미가 "crop 안에서 끝나는 반사"에서 "측선 전체의 지층"으로 바뀌고, 라벨 없는 이웃 crop에 라벨이 번진다). 대신 재라벨 지침의 "보이는 구간 전체, 가장자리까지"로 crop별 결과를 일치시킨다.

|---|---|---|
| 같은 층 조각 라벨(간격 ≤ 32 px 인접 쌍) | 이미지 463장 병합 대상, 박스 −25.6 % | 재라벨(사전 주석 = 조건부 32 px) |

## 한계

- M1-7 FP는 fold 0의 한 실행(`m17_aug0` seed 0)이다. seed 1(FP 549개)은 목록이 없어 연결하지 않았다.
- 시각 검토는 큐레이터 1인, 간격 구간 30장·FP 25장. 판정은 "이어짐/불확실" 수준이며 정밀 경계는 파일럿(2인)에서 재확인한다.
- v1은 균형화된 부분집합이라 이웃 crop 일부가 빠져 있다(겹침 분석은 v1 안 이웃만).
- 원본 XML을 읽지 않아 조각남의 기원이 XML인지 변환인지는 v1 감사와 같이 미확정이다.
